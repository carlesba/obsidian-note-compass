# Note Compass

[English](README.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

이 설명서는 기계 번역으로 작성된 초안이며, 기준이 되는 문서는 영어 README입니다.

Note Compass는 노트 이동, 속성 편집, 양식 작성과 직접 정의한 작업 명령을 위한 선택기를 제공합니다.

## 설치

Note Compass가 커뮤니티 플러그인 목록에 등록된 뒤에는 설정 → 커뮤니티 플러그인 → 탐색을 열고 "Note Compass"를 검색해 설치하고 활성화하면 됩니다.

직접 설치하려면 GitHub의 최신 릴리스에서 `main.js`, `manifest.json`, `styles.css`를 내려받으세요.

https://github.com/carlesba/obsidian-note-compass/releases/latest

세 파일을 `<vault>/.obsidian/plugins/note-compass/`에 넣고 Obsidian을 다시 불러온 다음, 설정 → 커뮤니티 플러그인에서 Note Compass를 활성화하세요.

Note Compass는 Obsidian 1.13.0 이상이 필요하며 데스크톱과 모바일 모두에서 동작합니다.

## 빠른 시작

이 명령어들은 키보드로 쓰도록 만들어졌으므로 먼저 각각에 단축키를 지정하세요. 설정 → 단축키를 열고 "Note Compass"를 검색한 다음 "탐색: 기본", "속성 설정", "양식 작성"에 키를 지정합니다. 명령어 팔레트에서 실행할 수도 있습니다.

전형적인 흐름은 이렇습니다. 오늘의 일일 노트를 열고 "탐색: 기본" 단축키를 눌러 어제 노트나 오늘 노트에서 링크한 노트로 이동합니다. 작업 중인 노트에서 "속성 설정" 단축키를 누르고 사람 이름을 몇 글자 입력해 고른 다음 "저장 후 닫기"를 선택합니다. 사람처럼 자주 만드는 노트가 있다면 설정 → Note Compass → 양식에서 양식을 추가하세요.

기본 설정에는 "기본" 탐색 선택기의 관계 목록 네 개와, "속성 설정"에서 자주 쓰는 체크박스 속성과 링크 속성 몇 개가 들어 있습니다. 설정 → Note Compass를 열어 쓰지 않는 항목은 끄고, 링크 속성이 내 폴더와 노트를 가리키도록 바꾸세요.

설정 → Note Compass → 작업에서 명령을 추가하고, 미완료 작업이 있는 노트에서 "열린 작업 처리"를 실행하세요. Enter는 완료를 대기시키고 `🏁 처리 끝내기`는 저장합니다.

## 노트로 이동

"노트로 이동"은 이동할 노트를 고르는 선택기를 엽니다. 행을 고르면 그 노트가 활성 탭에서 열리고, 열린 탭이 없으면 새 탭에서 열립니다.

설정 → Note Compass → 탐색에서 이름이 있는 탐색 선택기를 여러 개 만들 수 있으며, 각각 자체 목록이 있습니다. 각 선택기는 명령 팔레트에 "탐색: <이름>"으로 표시되므로 따로 단축키를 지정할 수 있습니다. 새로 설치하면 "기본"이라는 선택기 하나로 시작하고, 탐색 선택기 이전에 저장된 목록은 그대로 여기로 옮겨집니다. "노트로 이동"은 "어떤 탐색 선택기를 열까요?"라고 물으며 켜진 선택기를 모두 보여 주고, 고른 선택기를 엽니다.

![일일 노트에서 연 노트로 이동 선택기. 전날과 다음 날, 그 노트의 나가는 링크, 같은 날의 노트, 이번 주, 이번 달, 올해, 진행 중인 프로젝트, 사람이 표시됩니다](docs/images/jump-to-note.png)

각 선택기는 설정의 해당 선택기 페이지에서 구성한 목록을 설정한 순서대로 보여 줍니다. 사용할 수 있는 목록 중 네 가지는 포커스된 마크다운 노트를 기준으로 하므로, 다른 것에 포커스가 있거나 열린 탭이 없으면 표시되지 않습니다.

- 인접 날짜: 포커스된 노트 바로 앞과 뒤의 날짜 노트를 기간마다 나열합니다. 이전과 다음 날, 주, 달, 분기, 해가 대상입니다. 예: `📅 day 2024-03-06 (다음 날 - 수요일)`, `📅 day 2024-W09 (이전 주 - 9주차)`. 포커스된 노트보다 짧은 기간은 건너뛰므로 주 노트에서는 날이 나오지 않습니다. 어떤 항목을 어떤 순서로 나열할지, 없는 노트도 보여 줄지는 목록 페이지에서 고릅니다.
- 나가는 링크: 포커스된 노트가 링크하는 노트를 나열하며, 속성 안의 링크도 포함합니다.
- 들어오는 링크: 포커스된 노트로 링크하는 노트를 나열합니다.
- 같은 날: 포커스된 노트와 같은 날에 만들어진 노트를 나열합니다. 일 노트의 경우 파일을 만든 시점 대신 이름에 들어 있는 날짜를 기준으로 합니다.

나머지 목록은 포커스된 노트와 상관없이 동작합니다.

- 필터: 조건과 일치하는 노트를 나열합니다. 예를 들어 `status 같음 active`, `#project` 태그가 붙은 노트, 지난 일주일 동안 수정된 `work` 폴더의 노트 같은 조건입니다. 조건은 "목록 페이지"에서 설명하는 것처럼 그룹으로 묶을 수 있습니다.
- 노트로 링크: 선택한 노트로 본문이나 속성에서 링크하는 노트를 나열합니다.
- 폴더 안: 폴더와 그 하위 폴더의 노트를 나열합니다.
- 오늘 수정됨: 자정 이후 변경된 노트를 나열합니다.
- 현재 날짜 노트: 오늘, 이번 주, 이번 달, 이번 분기, 올해의 날짜 노트 중 켜 둔 것을 나열합니다. 이름순으로 정렬하지 않고 목록 페이지에서 정한 순서(기본값은 오늘부터 올해까지)를 따르며, 각 행에는 `이번 주 - 10주차`처럼 어느 기간인지 표시됩니다. 아직 없는 노트는 "아직 없는 노트도 표시"를 끄지 않았다면 `이번 주 만들기`로 표시되고, 고르면 사용 중인 날짜 노트 플러그인과 같은 방식과 같은 템플릿으로 노트를 만들어 엽니다. 이 플러그인은 Periodic Notes이거나, 일 노트라면 코어 플러그인인 일일 노트입니다. 사용자 지정 형식에서 가져온 기간은 빈 노트로 시작합니다. 링크 속성에서 이 소스를 쓰면 이미 있는 노트만 표시됩니다.

한 노트가 여러 목록에 들어 있으면 목록 순서대로 각 목록 아래에 모두 표시되며, 포커스된 노트는 빠집니다. 목록 안에서는 노트가 이름순으로 정렬됩니다. 어느 목록에도 노트가 없으면 빈 선택기를 여는 대신 "이동할 노트가 없습니다."라고 알려 줍니다.

모든 행은 해당 목록의 접두사로 시작하며, 접두사는 이름과 구분되도록 작은 칩으로 표시됩니다. 한 선택기의 모든 칩은 가장 넓은 칩의 너비(최대 약 12자)에 맞춰지므로 이름이 가지런히 정렬되고, 접두사 색상을 지정한 목록은 칩에 그 색이 입혀집니다. 날짜 노트는 이름 뒤에 기간을 덧붙입니다. 일 노트는 요일, 주 노트는 `N주차`, 월 노트는 `<월>`(예: `3월`), 연 노트는 `연도`입니다.

노트를 열지 않고 속성을 편집하려면 해당 행에서 ⌥↵(Alt+Enter)를 누르거나, 행 끝의 슬라이더 아이콘을 탭하세요. 이 아이콘은 데스크톱에서는 강조된 행에, 휴대폰에서는 모든 행에 표시됩니다. 어느 쪽이든 포커스된 노트 대신 그 노트에 대해 "속성 설정"을 엽니다. 없는 날짜 노트를 만드는 행에는 아이콘이 없습니다. 이렇게 연 "속성 설정"에서 Escape, `🛑 취소`, `🏁 저장 후 목록으로 돌아가기` 중 무엇을 눌러도 입력하던 내용 그대로 이동 목록으로 돌아가므로, 여러 노트를 연달아 편집할 수 있습니다.

입력하면 순서 일치 방식으로 행이 걸러집니다. 입력한 문자가 대소문자 구분 없이 같은 순서로 행에 들어 있으면, 사이에 다른 문자가 있어도 그 행이 남습니다. 접두사도 행의 일부이므로 접두사 일부를 입력하면 선택기가 해당 목록으로 좁혀집니다.

### 날짜 노트

노트가 해당 기간에 설정된 폴더 바로 안에 있고 이름이 그 기간의 형식과 정확히 일치하면 날짜 노트입니다. 기간은 일, 주, 월, 분기, 연 다섯 가지이며, 각각 폴더, 형식, 켜기/끄기 스위치를 따로 가집니다.

설정 기본 페이지의 "날짜 노트 원본" 설정은 이 형식을 어디서 가져올지 정합니다. "자동"은 Periodic Notes 플러그인이 활성화되어 있으면 그것을 쓰고, 아니면 코어 플러그인인 일일 노트를, 그다음에는 이 플러그인의 사용자 지정 형식을 씁니다. 일일 노트는 일만 다루므로 나머지 기간은 사용자 지정에서 가져옵니다. 사용자 지정에서 가져오는 기간이 있으면 "날짜 노트 원본" 옆의 연필 아이콘으로 형식 화면을 열 수 있고, 여기서 각 기간의 폴더와 Moment 형식을 설정합니다.

https://momentjs.com/docs/#/displaying/format/

기본값으로는 모든 기간이 `on/`에 `2024-03-05`, `2024-W10`, `2024-03`, `2024` 형태로 저장되며, `2024-Q1` 같은 분기는 꺼져 있습니다.

## 속성 설정

"속성 설정"은 포커스된 마크다운 노트의 속성을 하나의 선택기에서 편집합니다. 마크다운 노트에 포커스가 있을 때만 명령어 팔레트에 나타납니다.

선택기에서 작업하는 동안에는 아무것도 저장되지 않습니다. 첫 두 행은 항상 `🏁 저장 후 닫기`와 `🛑 취소`입니다. 앞의 것은 바꾼 속성만 저장하고, 뒤의 것은 모든 변경을 버립니다. Escape는 취소와 같습니다. ⌘↵(Windows와 Linux에서는 Ctrl+Enter)를 누르면 속성 자체의 선택기를 포함해 어디서든 지금까지의 내용을 저장하고 선택기를 닫습니다.

그다음에는 노트에 저장될 값이 `✓` 표시와 함께 나옵니다. 링크된 노트마다 한 행씩, 그리고 체크박스, 텍스트, 숫자, 날짜마다 값을 옆에 적은 한 행씩입니다. 이번에 바꾼 값에는 `•` 표시도 붙습니다. 설정된 링크를 고르면 그 링크가 제거되므로, 링크 목록 속성에서는 그 노트 하나만 빠집니다. 설정된 텍스트, 숫자, 날짜를 고르면 그 속성 자체의 선택기가 열리고, 설정된 체크박스는 "체크박스 동작" 설정에 따라 동작합니다.

설정된 값 아래에는 활성화된 각 속성이 추가할 수 있는 항목을 설정 순서대로 보여 줍니다.

- 링크 또는 링크 목록 속성은 소스의 노트 중 아직 설정되지 않은 노트를 최근에 수정된 순서로 나열합니다. 하나를 고르면 링크 목록 속성에는 추가되고, 링크 속성에서는 기존 노트를 대체합니다. 링크는 `["[[Alice]]", "[[Bob]]"]` 같은 목록으로 저장되며, 속성에 이미 있지만 소스가 제공하지 않는 링크도 그대로 유지됩니다.
- 설정되지 않은 텍스트, 숫자, 날짜, 날짜 및 시간 속성은 이름이 적힌 한 행으로 표시되며, 고르면 그 속성 자체의 선택기가 열립니다. 보관함에 이미 있는 값은 여기가 아니라 그 선택기에서 제공됩니다.
- 텍스트나 숫자 속성은 기본 메뉴 스위치를 켠 미리 설정된 값도 여기에 나열하므로, 한 번에 값을 설정할 수 있습니다.
- 텍스트 속성은 미리 설정된 값이 아닌 내용을 입력하면 `✏️ <property>: "<입력한 내용>" 사용`도 제공합니다.
- 설정되지 않은 체크박스는 이름이 적힌 한 행으로 표시됩니다. 기본값으로는 그 속성 자체의 선택기를 엽니다. "true와 값 없음 사이에서 전환"으로 설정하면 고를 때 `true`가 되고, `true`인 상태에서 다시 고르면 지워집니다. "true, false, 값 없음 순서로 순환"으로 설정하면 고를 때마다 값 없음에서 `true`, `false`, 다시 값 없음으로 한 단계씩 바뀝니다.

아무것도 입력하지 않으면 각 속성은 최대 다섯 개의 값을 보여 주고, 그 뒤에 `… N개 더 있음, 입력해서 필터링`이 이어집니다. 이 행을 고르면 속성의 접두사가 자동으로 입력됩니다. 입력을 시작하면 일치하는 행이 모두 표시됩니다. 값을 고르면 필터가 비워진 채로 선택기가 다시 열리므로, `🏁 저장 후 닫기`가 다시 맨 위에 오고 방금 고른 값은 그 아래에 설정된 값으로 표시됩니다.

"여러 속성" 모드의 행은 `status: done`, `archived: true`, `active` 없음처럼 여러 속성을 한 번의 선택으로 설정합니다. 값은 그 속성 페이지에서 고정되므로 선택기가 값을 묻지 않습니다. 이 행은 선택기에서 하나의 선택지로, "이름"으로 표시됩니다. 이름이 비어 있으면 `status done, archived ✓, active 지움` 같은 값 요약으로 표시되며, 속성은 보통 색상으로, 값은 회색으로 보입니다. 노트가 모든 값을 갖추지 않은 동안에는 이 행이 추가할 수 있는 항목 사이에 나오고, 고르면 모든 값이 한꺼번에 적용되고 필터가 비워진 채 선택기가 다시 열립니다. 노트가 모든 값을 갖추면 이 행은 설정된 값 사이에 `✓` 표시와 함께 나오고, 선택기를 열 때 갖추지 않았다면 `•` 표시도 붙습니다. 이때 고르면 아무것도 바뀌지 않습니다. 링크 목록 값은 그 노트를 추가하고 다른 링크는 유지하며, 링크 값은 노트를 바꾸고, 지운 값은 속성을 삭제합니다. 오늘과 지금은 선택기를 열 때 정해집니다. 이 행은 전부 아니면 전무여서, 모든 값을 갖출 때만 설정된 것으로 보이고, 저장하기 전까지는 아무것도 기록되지 않습니다.

속성 자체의 선택기는 현재 값에 `✓`를 표시하고 마지막에 `🗑️ 지우기`를 보여 줍니다. 이 행은 속성을 삭제하거나, "비면 삭제"가 꺼져 있으면 속성을 빈 값으로 남깁니다. Escape를 누르면 그 속성을 바꾸지 않고 기본 선택기로 돌아가며, 기본 선택기에서 이미 한 변경은 유지됩니다.

- 체크박스는 `true`와 `false`를 제공합니다.
- 텍스트는 새 값을 위한 `✏️ "<입력한 내용>" 사용`, 이어서 미리 설정된 값, 그다음 보관함에서 이 속성이 이미 가진 다른 값을 많이 쓰인 순서로 사용 횟수와 함께 제공합니다.
- 숫자는 숫자를 위한 `✏️ "<입력한 내용>" 사용`, 이어서 미리 설정된 값, 그다음 보관함에서 이 속성이 이미 가진 다른 숫자를 많이 쓰인 순서로 제공합니다.
- 날짜는 `YYYYMMDD`나 `YYYY-MM-DD`로 입력한 날짜에 대한 "사용", 이어서 오늘, 내일, 다음 월요일, 일주일 후를 제공하며, `YYYY-MM-DD`로 저장됩니다.
- 날짜 및 시간은 `YYYYMMDDHHmm`, `YYYYMMDD HHmm`, `YYYY-MM-DD HH:mm`, `YYYY-MM-DDTHH:mm`에 대한 "사용", 이어서 지금을 제공하며, `YYYY-MM-DDTHH:mm`으로 저장됩니다.

![날짜 속성의 값 선택기. 오늘, 내일, 다음 월요일, 일주일 후, 지우기가 있습니다](docs/images/set-properties-date.png)

링크 속성은 포커스된 노트와 속성의 제외 폴더에 있는 노트를 절대 제공하지 않습니다. 보관된 노트 같은 것을 숨기려면 `archived 참임`을 담은 "다음 중 참인 것이 존재하지 않음" 그룹이 있는 필터를 소스로 쓰세요. 선택기는 이미 있는 노트만 링크하므로, 새 노트를 링크하려면 먼저 양식으로 만드세요.

## 양식

양식은 몇 가지 질문으로 새 노트 하나를 만듭니다. 예를 들어 책과 저자를 묻는 독서 기록이나, 주제와 참석자를 묻는 회의 노트가 있습니다. 양식은 설정 → Note Compass → 양식에서 정의합니다. "양식 작성"은 활성화된 양식을 나열하고 고른 양식을 실행합니다. 활성화된 양식은 각각 양식 이름을 딴 별도의 명령어이기도 하므로 단축키를 지정할 수 있습니다. 다른 명령어처럼 포커스된 노트가 있든 없든 동작합니다. 양식이 없으면 "양식 작성"은 "아직 양식이 없습니다. 설정 → Note Compass → 양식에서 추가하세요."라고 표시합니다.

양식은 질문 필드마다 질문을 하나씩, "필드" 목록의 순서대로 묻습니다. Escape를 누르면 이전 질문으로 돌아가고, 첫 질문에서 Escape를 누르면 노트를 만들지 않고 양식을 닫습니다. 돌아가도 이미 입력한 답변은 남아 있으며 체크 표시가 붙습니다.

마지막 질문이 끝나면 요약이 열립니다. 첫 행은 답변으로 정해진 노트 이름이 들어간 `✅ "<이름>" 만들기`이고, 그다음에 필드마다 한 행씩 들어갈 값이나 `건너뜀`이 표시되며, 마지막에 `🛑 취소`가 있습니다. 질문 필드를 고르면 그 질문이 다시 열리고, 답하면 요약으로 돌아옵니다. 요약에서 Escape를 누르면 마지막 질문으로 돌아가며, 질문이 없는 양식이면 양식을 닫습니다. ⌘↵(Windows와 Linux에서는 Ctrl+Enter)를 누르면 필수 질문에 모두 답한 뒤라면 어떤 질문에서든 노트를 만듭니다.

노트는 양식의 "폴더"에 만들어지고, 비어 있으면 Obsidian이 새 노트를 두는 곳에 만들어집니다. 그곳에 대소문자를 무시하고 같은 이름의 노트가 이미 있으면 새 노트에는 `Dune 2`처럼 번호가 붙습니다. 노트 본문이 먼저 기록되고, 그다음 필드 순서대로 속성이 기록됩니다. 그런 다음 Note Compass가 `reading에 "Dune"을(를) 만들었습니다.`처럼 노트를 만든 곳을 알려 주고, "만든 후 노트 열기"가 꺼져 있지 않으면 노트를 엽니다.

### 양식 페이지

양식 페이지에는 다음 항목이 있습니다.

- "활성화": 양식을 "양식 작성"과 명령어에 표시합니다.
- "이름": "양식 작성"과 명령어 이름에 표시됩니다.
- "노트 이름": 새 노트 이름의 패턴입니다. 예: `{{date:YYMMDDHHmm}} {{book}}`. 빈 자리 표시자 때문에 겹친 공백은 하나로 합쳐지며, 이름이 비게 되거나 Obsidian이 파일 이름에 쓸 수 없는 문자가 들어가면 메시지와 함께 거부되고 요약에 그대로 머뭅니다.
- "노트 내용": 새 노트의 본문으로, 같은 자리 표시자를 쓸 수 있습니다.
- "폴더": 새 노트가 저장될 곳입니다.
- "만든 후 노트 열기": 기본으로 켜져 있습니다.
- "필드": 양식이 채우거나 묻는 값입니다. 이 순서가 질문 순서입니다.

필드 목록은 설정의 다른 목록과 똑같이 동작합니다. 핸들을 끌어 순서를 바꾸고, 복사 아이콘으로 필드를 바로 아래에 복제하며, X로 필드를 삭제하고, 머리글의 `+`로 필드를 추가합니다. `+`를 누르면 메뉴가 열립니다. "빈 필드"는 비어 있는 텍스트 질문 필드를 추가하고, "날짜", "시간", "타임스탬프", "ISO 타임스탬프"는 만들 때의 값이 들어가는 고정 필드를 추가합니다. 키는 `date`, `time`, `timestamp`, `iso-timestamp`이고 형식은 `YYYY-MM-DD`, `HH:mm`, `YYYY-MM-DDTHH:mm`, ISO 8601입니다. 각 항목에는 지금 기록될 값이 표시되며, 이미 쓰이는 키에는 `timestamp-2`처럼 번호가 붙습니다. "항목 날짜 확인"과 "항목 시간 확인"은 질문 변수 `entry-date`와 `entry-time`을 추가하며, 둘 다 사용할 수 있습니다.

날짜는 `YYYYMMDD`, 시간은 `HHmm` 텍스트로 입력합니다. 아래 옵션은 전체 `YYYY-MM-DD HH:mm`을 보여 주고 Enter로 표시 값을 유지합니다. 날짜 변경은 시간을, 시간 변경은 날짜를 유지하며 최종 검토에서 다시 편집해도 유지됩니다. 결합된 날짜/시간은 `{{date}}`, `{{time}}`, 노트 이름과 "생성 시" 고정 필드에 사용됩니다. 기존 설정은 유지되고 날짜 및 시간 유형은 전체 시점을 바꿉니다. 같은 부분을 바꾸는 필드가 중복될 때만 경고합니다. 각 행에는 필드의 키가 표시되고, 그 뒤에 저장 위치, 모드, 유형을 나타내는 작은 배지가 `book` `변수` `질문` `텍스트`처럼 이어집니다. 속성 배지는 파란색이고 변수 배지는 보라색입니다. 행이나 그 화살표를 클릭하면 바로 아래에서 필드를 편집할 수 있고, 다시 클릭하면 닫힙니다. 한 번에 하나의 필드만 열리며, 새 필드는 바로 열립니다.

이름과 내용에서는 다음 자리 표시자를 쓸 수 있습니다.

- `{{date}}`와 `{{time}}`은 양식을 시작한 시각이며, 코어 플러그인인 템플릿에 설정된 형식을 따릅니다. `{{date:FORMAT}}`과 `{{time:FORMAT}}`은 지정한 형식을 씁니다.
- `{{key}}`는 이름이 `key`인 필드의 값입니다. 목록은 쉼표로 이어지고, 건너뛴 필드는 비어 있습니다.
- `{{key:FORMAT}}`은 날짜나 시간 필드를 지정한 형식으로 나타냅니다. 예: `{{started:dddd}}`.
- `{{title}}`은 내용에서만 쓸 수 있으며 새 노트의 이름입니다.

그 밖의 자리 표시자는 그대로 남습니다.

### 필드

모든 필드에는 "키", "저장 방식", "채우는 주체", 질문 필드라면 "질문", 그리고 "필드 종류"가 있습니다. "키"는 속성 이름이나 변수 이름이며, 두 경우 모두 `{{key}}`로 씁니다. "저장 방식"은 값을 키 이름으로 새 노트의 속성에 기록하는 "속성"(기본값)이거나, 이름과 내용의 자리 표시자만 채우고 기록되지 않는 "변수"입니다. "채우는 주체"는 "고정값" 또는 "질문"입니다.

고정 필드는 텍스트, 숫자, 체크박스, 목록, 날짜, 시간, 날짜 및 시간 중 하나입니다. 숫자는 숫자만 받고, 체크박스에는 스위치가 있습니다. 목록에는 입력란이 있고 각 항목은 칩으로 표시됩니다. 항목을 입력하고 Enter를 눌러 추가하고, 항목의 ×로 제거합니다. 항목은 링크일 수도 있으므로 `[[Books]]`와 `[[Reading]]`은 `categories: ["[[Books]]", "[[Reading]]"]`을 기록합니다. 양식은 이렇게 노트를 다른 노트에 링크합니다. 고정 텍스트 값이나 목록의 입력란에 `[[`를 입력하면 보관함의 노트가 제안되고, 하나를 고르면 `[[Books]]`처럼 그 링크가 기록됩니다. 폴더는 두 노트의 이름이 같을 때만 붙습니다. 목록의 입력란에서는 고른 링크가 바로 칩이 됩니다.

질문 필드는 텍스트, 숫자, 체크박스, 선택, 다중 선택, 날짜, 시간, 날짜 및 시간 중 하나입니다. "질문"은 표시되는 물음이며, 비어 있으면 필드의 키를 씁니다. "선택 사항"을 켜면 질문 맨 앞에 `⏭️ 건너뛰기`가 나옵니다. 건너뛴 속성은 전혀 기록되지 않고, 건너뛴 변수는 비어 있습니다. 텍스트나 숫자 질문에는 무엇이든 입력할 수 있고, 텍스트나 숫자 속성은 보관함에서 그 속성에 이미 쓰인 값도 보여 줍니다.

선택과 다중 선택에는 "선택지"가 있으며, 각 선택지에는 값과 생략할 수 있는 레이블이 있습니다. "선택지" 머리글의 `+`로 추가하고, X로 제거하며, 선택지의 핸들을 끌어 순서를 바꿉니다. 질문에는 레이블이, 레이블이 없으면 값이 표시되고, 노트에는 값이 들어갑니다. 다중 선택 질문에서는 선택지를 여러 개 고를 수 있고 고른 것에는 체크 표시가 붙으며, `🏁 완료`로 마칩니다. "선택지 값 형식"은 값을 텍스트나 숫자로 기록하므로, 값이 `4`이고 레이블이 `4 · 최고`인 선택지는 숫자 4를 기록할 수 있습니다.

날짜, 시간, 날짜 및 시간 필드에는 "형식"이 있습니다. `YYYY-MM-DD`, `HH:mm`, `YYYY-MM-DDTHH:mm`, ISO 8601, 또는 사용자 지정 Moment.js 형식입니다. 고정 필드는 "값"을 양식을 시작한 시각인 "만들 때"에서, 그 아래에 입력하는 날짜인 "지정한 날짜"에서, 또는 양식의 다른 날짜·시간 필드의 값인 "… 필드에서"에서 가져옵니다. 지정한 날짜는 숫자로, 날짜는 `YYYYMMDD`, 시간은 `HHmm`, 날짜 및 시간은 `YYYYMMDDHHmm` 형식으로 입력하며, 하이픈과 콜론을 넣어도 됩니다. 그 아래 줄에는 `✓ Mon 30 Oct 2028, 09:00`처럼 읽은 결과가 표시됩니다. 그래서 질문한 시간 하나로 `YYYY-MM-DD` 형식의 `day`와 ISO 8601 형식의 `timestamp`처럼 여러 속성을 채울 수 있습니다. 가져오는 필드를 건너뛰면 이 필드도 건너뜁니다. 질문 필드는 "지금"을 보여 주고, 날짜는 "오늘", "내일", "다음 월요일", "일주일 후"도 보여 줍니다. "속성 설정"의 날짜 선택기처럼 `20240311`, `2024-03-11`, `0930`, `09:30`, `202403110930`, `20240311 0930`을 입력할 수도 있습니다. 시간은 오늘의 그 시각이 됩니다.

블록은 앞선 답이 일치할 때만 양식이 쓰는 필드를 묶습니다. 예를 들어 노트가 책에 관한 것일 때만 쪽수를 물을 수 있습니다. "필드" 머리글의 `+` 메뉴에서 "조건부 블록"을 고르면 빈 블록이 목록 끝에 추가되고, 블록 아래쪽의 `+`는 그 안에 필드를 추가합니다. 필드를 블록 머리글과 아래쪽 행 사이로 끌면 블록에 들어가고, 밖으로 끌면 다시 목록으로 나옵니다. 머리글을 끌면 블록 전체가 움직이며, 블록은 다른 블록 안에 들어갈 수 없습니다. 블록을 삭제해도 그 필드는 목록에 남습니다. 머리글을 클릭해 조건을 편집합니다. 각 조건은 블록 위의 필드, 필드 종류에 따른 "같음", "항목 있음", "=", "이전", "값 있음" 같은 검사, 그리고 대부분의 경우 값을 고릅니다. 선택 필드는 선택지를 값으로 보여 주고, 날짜와 시간은 `YYYYMMDD`, `HHmm`, `YYYYMMDDHHmm`으로 입력합니다. 블록은 모든 조건이 맞을 때만 쓰입니다. 쓰이지 않는 블록의 질문은 묻지 않고, 필드는 요약에 나오지 않으며 기록되지 않고, 자리 표시자는 비어 있습니다. 여러 필드가 같은 키를 쓸 수 있습니다(두 블록 각각의 `categories` 등). 값이 있는 마지막 필드가 이기며, 건너뛴 필드는 앞 필드의 값을 지우지 않습니다.

키가 없는 필드, 선택지가 없는 선택, 날짜가 아닌 필드에서 가져오는 날짜는 필드 행과 양식에 경고를 표시합니다. 조건이나 필드가 없는 블록, 필드나 값이 없는 조건, 블록 위에 없는 필드에 대한 조건, 필드 종류에 맞지 않는 조건은 블록 행과 양식에 경고를 표시합니다. 이 버전의 Note Compass가 읽을 수 없는 양식은 읽을 수 없는 목록처럼 꺼진 채로 경고와 함께 연필 없이 목록에 남으며, 저장된 설정은 삭제할 때까지 유지됩니다.

## 작업 명령

직접 정의한 명령 팔레트 명령으로 활성 Markdown 노트의 작업을 처리합니다.

### 빠른 시작

설정 → Note Compass → 작업의 `+`로 명령을 추가하고 이름을 지정하세요. Markdown 노트를 연 뒤 명령 팔레트에서 그 이름을 실행합니다. 단축키도 지정할 수 있습니다. 활성화되어 있고 동작이 하나 이상인 명령만 제공됩니다. 일치하는 작업이 없으면 빈 선택기 대신 알림이 표시됩니다.

![일일 노트에서 연 작업 선택기. 맨 위에 ⚡ 작업 5개 모두에 적용, 그 아래에 미완료 작업, 이어서 변경 개수가 붙은 🏁 처리 끝내기, 마지막에 🛑 취소가 있습니다](docs/images/task-picker.png)

### 명령 페이지

| 설정 | 기능 |
| --- | --- |
| 활성화 | 이 작업 명령을 별도의 명령으로 제공합니다. |
| 이름 | 명령 팔레트에서 명령 이름으로 표시됩니다. |
| 표시할 작업 | 비워 두면 모든 작업을 표시합니다. |
| 건너뛸 작업 | 표시 대상이어도 제외합니다. 비워 두면 아무것도 건너뛰지 않습니다. |
| 모두 선택 | 표시된 모든 작업에 동작을 적용하는 첫 행을 추가합니다. |
| 일괄 모드 | 완료하거나 남은 작업이 없을 때까지 동작을 저장하지 않고 대기시킵니다. 취소 또는 Esc를 누르면 대기 중인 변경 사항을 모두 버립니다. |
| 키 설정 | Enter, Cmd+Enter(Windows와 Linux에서는 Ctrl+Enter), Alt+Enter, Shift+Enter에 동작, "동작 메뉴 표시", 또는 일괄 모드에서는 `🏁 처리 끝내기`를 지정합니다. `+`로 추가하고 ×로 제거합니다. 키마다 한 번만 쓸 수 있습니다. 지정되지 않은 키는 동작 메뉴를 열므로, 목록이 비어 있으면 어떤 키든 메뉴를 엽니다. 동작을 삭제하면 그 동작의 키도 사라집니다. |

"상태 추가"는 미완료 `[ ]`, 완료 `[x]`, 취소됨 `[-]`, 이동됨 `[>]`, 예약됨 `[<]`, 진행 중 `[/]` 및 "사용자 지정…"을 제공합니다. 사용자 지정 상태는 문자 하나를 입력하고 Enter로 추가하며, 칩의 ×로 제거합니다. 대소문자를 구분하고 건너뛰기가 우선합니다.

양식과 작업 행은 이름만 표시합니다. 두 번째 줄은 경고가 있을 때만 표시하며 설정 요약은 표시하지 않습니다.
읽을 수 없는 명령은 삭제할 때까지 꺼진 채 경고와 함께 보존됩니다.

### 동작

각 동작에는 "레이블", 하나의 "동작" 유형, 한 글자의 "상태"가 있습니다. `+`로 추가하고, 끌어서 정렬하고, 복사 아이콘으로 복제하고, ×로 삭제합니다. 행을 클릭하면 바로 아래에서 편집합니다.

#### 상태 변경

원본 행의 체크박스 문자를 바꿉니다. "완료 날짜"로 접미사를 추가할 수 있습니다.

| 완료 날짜 | 추가할 텍스트 |
| --- | --- |
| 끔 | 없음. |
| 날짜 | ` ✅ 2028-10-30` |
| 날짜 링크 | ` ✅ [[2028-10-30]]` |
| 날짜 및 시간 | ` ✅ 2028-10-30 09:00` |

예제 날짜는 "날짜 노트"의 일일 형식을 사용하며 원본 노트 날짜가 아닌 오늘입니다. 날짜 및 시간은 코어 템플릿 플러그인의 시간 형식을 더합니다. 날짜 링크는 노트를 만들지 않습니다.

#### 노트로 복사

다른 노트 끝에 미완료 작업 `[ ]`을 추가하고 원본의 "상태"를 바꿉니다. 작업 한 줄만 복사하며 하위 작업, 이어지는 줄, 들여쓰기와 인용 접두사는 복사하지 않습니다.

- "대상"은 별도 페이지를 엽니다. `+`로 추가하고 끌어서 순서를 바꾸며 ×로 삭제합니다. 뒤로 화살표로 명령에 돌아갑니다.
- 복사된 작업의 접두사와 접미사는 복사본 본문에만 그대로 적용되고 블록 ID와 원본 링크 앞에 들어갑니다. 필요한 공백을 포함하세요. 기본값은 비어 있고 즉시 처리와 일괄 처리 모두에 적용됩니다.
- "대상 링크"는 원본에 ` → [[대상]]`을, "원본 링크"는 복사본에 ` ← [[원본]]`을 추가합니다.
- 기간은 원본 노트 날짜가 아니라 오늘을 기준으로 하며, "날짜 노트"의 활성 기간, 폴더와 형식을 사용합니다. 가능한 대상이 하나면 바로 실행하고, 여러 개면 설정 순서대로 "어느 노트로 복사할까요?"를 엽니다. 원본 노트와 중복 대상은 제공하지 않습니다.
- 없는 특정 노트는 알림과 함께 제외합니다. 대상이 남지 않으면 아무것도 바꾸지 않습니다.
- 없는 주기 노트는 저장할 때 만듭니다. "날짜 노트"가 Periodic Notes를 사용하면 먼저 해당 플러그인에 템플릿을 사용한 생성을 요청합니다. API가 없거나 실패하거나 예상 경로에 생성하지 않으면 빈 노트를 만듭니다. 코어 일일 노트와 사용자 지정을 포함한 다른 소스는 빈 노트에 작업을 추가합니다.

![이전 동작의 "어느 노트로 복사할까요?" 선택기. 내일, 이번 주, 새 노트로 표시된 다음 주, 이번 달이 각각 노트 이름과 함께 표시됩니다](docs/images/task-destinations.png)

### 선택기와 일괄 모드

![동작 메뉴 "어떤 동작을 적용할까요?". ✅ 완료, 🚫 취소, ➡️ 이전, 📅 일정 잡기가 표시됩니다](docs/images/task-actions.png)

- 입력하면 대소문자를 구분하지 않고 문자 순서로 작업 텍스트를 필터링합니다. "키 설정"의 키는 지정된 동작을 실행하고, 다른 키나 ⚙는 모든 동작을 엽니다.
- "모두 선택"은 검색에 일치하는 작업이 둘 이상일 때 `⚡ 작업 N개 모두에 적용`을 추가합니다. 노트 전체가 아니라 검색과 일치하는 작업만 대상입니다.
- "일괄 모드"에서는 선택을 대기시키고, 남은 작업과 빈 검색으로 선택기를 다시 엽니다. `🏁 처리 끝내기` · 변경 N개는 모두 저장합니다. 작업 선택기의 `🛑 취소` 또는 Escape는 모두 버립니다. 동작이나 대상 선택기의 Escape는 기존 대기 변경을 유지한 채 돌아갑니다.
- 마지막 작업을 처리하면 자동으로 저장하고 끝냅니다. `⚡ 작업 N개 모두에 적용`도 검색에 숨겨진 다른 작업이 있어도 즉시 저장하고 끝냅니다.
- "일괄 모드"가 꺼져 있으면 한 번의 선택을 즉시 저장하고 선택기를 닫습니다. Escape로 되돌릴 수 없습니다. 두 모드 모두 선택기를 연 뒤 수정된 원본 줄은 알림과 함께 건너뜁니다.

### 새 명령의 기본값

새 명령은 "열린 작업 처리"라는 Bullet Journal 설정으로 시작합니다. 활성화되어 있으며 미완료 `[ ]`만 표시하고 제외는 없습니다. "모두 선택"은 꺼져 있고 "일괄 모드"는 켜져 있습니다. "키 설정"은 Enter를 "✅ 완료"에 지정하므로 Alt+Enter, Cmd+Enter, Shift+Enter는 동작 메뉴를 엽니다.

| 동작 | 원본 상태 | 다른 설정 |
| --- | --- | --- |
| ✅ 완료 | `[x]` | 완료 날짜: 끔. |
| 🚫 취소 | `[-]` | 완료 날짜: 끔. |
| ➡️ 이전 | `[>]` | 내일, 이번 주, 다음 주, 이번 달; 대상만 링크합니다. |
| 📅 일정 잡기 | `[<]` | 다음 달, 다음 분기, 내년; 대상과 원본을 링크합니다. |

이 기본 대상은 새 명령에만 적용되며 저장된 대상은 바뀌지 않습니다.

### 알려진 동작
- 여러 노트에 걸친 쓰기는 원자적이지 않습니다. 실패하면 일부 노트만 바뀔 수 있습니다.
- 복사는 기존 접미사와 블록 ID를 포함한 행 텍스트를 유지합니다. 블록 ID는 새로 생성되지 않고 중복됩니다.

## 설정

설정은 좁은 창에도 맞게 배치되며 모바일에서도 똑같이 동작합니다. 기본 페이지는 "탐색", "속성", "양식", "작업" 네 페이지가 각각 무엇을 담는지 알려 주는 짧은 안내로 시작하고, 이어서 네 페이지, "연동" 그룹의 "날짜 노트 원본", 마지막에 "모든 설정 초기화"가 있습니다.

![설정 기본 페이지. 맨 위에 Note Compass의 구성 안내, 이어서 탐색, 속성, 양식, 작업 페이지, 연동 아래의 날짜 노트 원본, 맨 아래에 모든 설정 초기화가 있습니다](docs/images/settings.png)

네 행 중 하나의 어느 곳이든 클릭하면 그 페이지가 열리고, 위쪽의 뒤로 화살표로 돌아갑니다. 행 자신의 페이지는 그 섹션 안에서 열리므로, 목록의 페이지에서 돌아가면 해당 탐색 선택기 페이지에, 한 번 더 돌아가면 탐색 페이지에 도착합니다. 각 탐색 선택기에는 "필터"가 있어 각 목록의 원본과 필터에 더해 모든 목록에 적용되며, 일치하는 노트만 표시됩니다. 비어 있으면 아무것도 숨기지 않습니다. 새 선택기는 목록 없이 빈 필터로 시작하고, 복사 아이콘은 필터와 모든 목록을 함께 복제합니다.

![탐색 선택기 페이지. 각 목록이 접두사 칩, 스위치, 복사 아이콘, 연필, 삭제 버튼이 있는 행으로 표시됩니다](docs/images/settings-jump-to-note.png)

### 양식과 작업

다른 목록과 같은 추가, 정렬, 활성화, 편집, 복제, 삭제 컨트롤을 사용합니다. 명령 페이지에는 명령, 표시할 작업, 건너뛸 작업, 옵션, 동작이 있습니다. 추가하기 전에는 작업 명령이 없으며 새 명령은 Bullet Journal 동작으로 시작합니다.

양식과 작업 행은 이름만 표시합니다. 두 번째 줄은 경고가 있을 때만 표시하며 설정 요약은 표시하지 않습니다.

### 목록과 속성

탐색 선택기 페이지와 속성 페이지는 모두 행으로 이루어진 목록이며, 행은 같은 방식으로 동작합니다. 각 행에는 접두사 칩과 나열하거나 쓰는 대상이 `status 같음 active`, `people · 링크 목록`처럼 표시됩니다.

- 왼쪽 핸들을 끌어 행 순서를 바꿉니다. 이 순서가 선택기의 순서입니다.
- 스위치로 설정을 잃지 않고 선택기에서 행을 표시하거나 숨깁니다.
- 연필로 행의 페이지를 열고, X로 행을 삭제합니다.
- 복사 아이콘으로 행을 복제합니다. 복제본은 같은 설정으로 바로 아래에 생기며, 양식의 복제본 이름은 `<이름> 사본`입니다.
- 목록 위의 `+`로 행을 추가합니다. 바로 페이지가 열려 내용을 채울 수 있고, 새 행은 켜진 상태로 시작합니다.

더 새로운 버전에서 저장한 행처럼 이 버전의 Note Compass가 읽을 수 없는 행은 "이 버전의 Note Compass로는 이 목록을 읽을 수 없습니다. 삭제하고 새로 만드세요."라는 경고와 함께 목록에 남습니다. 스위치는 꺼진 채로 비활성화되고 연필도 없으므로 선택기에 노트를 추가하지 않지만, 저장된 설정은 삭제할 때까지 그대로 유지됩니다.

접두사 칩을 클릭하거나 탭하거나, 칩에 포커스를 두고 Enter를 누르면 메뉴가 열립니다. 휴대폰에서는 메뉴가 아래에서 올라오는 시트로 표시됩니다. 메뉴에는 모든 탐색 선택기와 속성 페이지에서 쓰이는 모든 접두사가 칩으로 표시되고, 그 뒤에 해당 접두사를 쓰는 행 수가 붙습니다. 예를 들어 `📅 due` 칩 뒤에 `· 3개 행`이 표시되며, 많이 쓰이는 접두사가 먼저 나옵니다. 행 자신의 접두사에는 체크 표시가 붙습니다. 하나를 고르면 그 텍스트와 색상이 이 행에만 적용되고 다른 행은 바뀌지 않습니다. "접두사 편집…"은 그 행의 페이지를 열고 "접두사"에 커서를 둡니다. "접두사 없음"은 행에 접두사가 있을 때만 나타나며, 텍스트와 색상을 지웁니다. 빈 접두사는 흐린 `접두사` 칩으로 표시되고 메뉴에는 나오지 않습니다.

텍스트와 색상이 모두 같을 때 두 행이 접두사를 공유합니다. 그래서 빨간색 `👤 peop`과 색상이 없는 `👤 peop`은 서로 다른 접두사입니다.

### 목록 페이지

목록 페이지에는 "활성화"와 "접두사"가 있고, 그다음 목록에 담을 대상을 정하는 "소스"가 있습니다. 소스는 인접 날짜, 나가는 링크, 들어오는 링크, 같은 날, 필터, 노트로 링크하는 노트, 폴더 안의 노트, 오늘 수정된 노트, 현재 날짜 노트 중에서 고릅니다. 인접 날짜와 현재 날짜 노트에는 소스 아래에 설정이 두 개 더 있습니다. "아직 없는 노트도 표시"를 끄면 이미 있는 날짜 노트만 나열하고, 켜면 `다음 주 만들기`처럼 없는 노트도 나열하며 고르면 만듭니다. 기본값은 인접 날짜에서는 꺼짐, 현재 날짜 노트에서는 켜짐입니다. "나열할 노트"에는 항목마다 한 행씩 있고 기본적으로 모두 켜져 있습니다. 인접 날짜는 "전날"과 "다음 날"부터 "이전 해"와 "다음 해"까지, 현재 날짜 노트는 "오늘"부터 "올해"까지입니다. 행의 핸들을 끌어 선택기에 표시되는 순서를 바꾸고, 행을 끄면 그 항목은 빠집니다. 없는 인접 날짜 노트는 날짜 노트 원본이 Periodic Notes이면 그 템플릿으로, 그 밖에는 빈 노트로 만들어집니다.

![인접 날짜 목록의 페이지. "아직 없는 노트도 표시"가 꺼져 있고, 그 아래 "나열할 노트"에 전날, 다음 날, 이전 주, 다음 주 등 기간이 있으며 각 행에 스위치와 끌기 핸들이 있습니다](docs/images/list-adjacent-dates.png)

목록이나 속성 페이지에서 "접두사"는 설정 버튼, 칩의 미리 보기, 텍스트, 색상을 보여 줍니다. 입력한 텍스트와 고른 색상은 이 행과, 페이지를 열 때 같은 접두사를 쓰던 모든 행에 적용되며, 설명에 그 행들이 표시됩니다(예: "다른 2개 행에서도 사용 중: people · 링크 목록, 나가는 링크"). 텍스트가 잠시 비어 있어도 그 행들은 함께 유지됩니다. 원형 화살표로 색상을 제거합니다.

설정 버튼("접두사 선택")을 누르면 접두사 메뉴가 열립니다. 접두사 하나를 고르면 그 텍스트와 색상이 이 행에 적용되고, 다른 행은 바뀌지 않습니다. "새 접두사…"는 행에 접두사가 있을 때만 나오며, 접두사를 비우므로 그다음에 입력하고 고른 것은 이 행에만 적용됩니다. "접두사 없음"은 행에 접두사가 있을 때만 나오며, 텍스트와 색상을 지웁니다.

필터는 Obsidian 베이스의 필터와 같은 방식으로 동작하고 생김새도 같습니다. 필터는 "다음 중 전체가 참임", "다음 중 하나 이상이 참임", "다음 중 참인 것이 존재하지 않음" 중 하나로 시작하는 그룹이며, 노트가 그룹의 모든 필터와 일치하는지, 하나 이상과 일치하는지, 아무것과도 일치하지 않는지에 따라 나열됩니다. 각 필터 행은 검사할 대상으로 시작합니다. 속성 이름을 입력하거나, 제안 목록에서 `폴더`, `태그`, `링크`, `생성된 시간`, `수정된 시간`을 고르세요. 그다음 연산자와 값을 고릅니다. 예: `폴더 안에 있음 projects`, `태그 포함 client`, `수정된 시간 이후 7일 전`. "필터 추가하기"는 그룹에 행을 추가하고, "필터 그룹 추가하기"는 그 안에 자체 선택을 가진 그룹을 추가합니다. 그룹은 필터 자체를 포함해 세 단계까지 겹칠 수 있습니다. 행이나 안쪽 그룹의 휴지통 버튼으로 삭제할 수 있고, 안쪽 그룹의 마지막 행을 삭제하면 그룹도 함께 삭제됩니다. 새 필터는 행이 없어서 행을 추가하기 전까지 아무것도 나열하지 않으며, 필터 안의 빈 그룹은 일치 판정에서 제외됩니다.

각 조건은 무엇을 볼지 고르는 것으로 시작합니다.

- 속성: 속성을 그 유형에 맞는 조건으로 검사합니다. 자세한 내용은 아래에 있습니다.
- 폴더: "안에 있음"이면 폴더와 하위 폴더의 노트와, "안에 없음"이면 나머지 모든 노트와 일치합니다.
- 태그: 속성이나 본문에 태그가 있는 노트와 일치합니다. 태그는 하위 태그와도 일치하므로 `project`는 `#project/website`와 일치하며, 대소문자와 앞의 `#`는 상관없습니다. "포함 안 함"은 그 태그가 없는 노트와 일치합니다.
- 노트로 링크: 선택한 노트로 본문이나 속성에서 링크하는 노트와 일치하고, "포함 안 함"은 링크하지 않는 노트와 일치합니다.
- 생성일과 수정일: 노트를 만든 날이나 마지막으로 바꾼 날을 고정 날짜 또는 오늘 기준 날짜와 같은 날, 다른 날, 이전, 이후로 비교합니다.

목록의 행에는 `status 같음 active`나 `태그 project 있음`처럼 필터의 유일한 조건이 표시되거나, `조건 3개 모두`처럼 조건 수가 표시됩니다.

이전 버전에서 "Notes with a property"로 저장한 목록은 그 속성 조건 하나를 가진 필터로 열리며, 전과 같은 노트를 나열합니다.

속성 조건은 먼저 속성을 묻는데, 보관함의 속성을 유형과 함께 제안합니다. 그다음 그 유형에 맞는 조건을 고릅니다.

- 체크박스 속성: 참, 거짓, 값 있음, 값 없음을 검사합니다. "거짓임"은 명시적인 `false`가 필요합니다.
- 텍스트 속성: 값과 같음, 같지 않음, 포함, 포함 안 함, 값 있음, 값 없음을 검사합니다.
- 목록, 태그, 별칭 속성: 값과 같은 항목이 있음, 없음, 값 있음, 값 없음을 검사합니다. 위키 링크는 링크 텍스트로 비교하므로 `[[Project]]`는 값 `Project`와 일치합니다.
- 숫자 속성: 숫자와 같음(`=`), 같지 않음(`≠`), 미만(`<`), 초과(`>`), 값 있음, 값 없음을 검사합니다.
- 날짜 속성: 고정 날짜, 오늘, 며칠 전 또는 며칠 후와 같은 날, 다른 날, 이전, 이후인지와 값 있음, 값 없음을 검사합니다. 상대 날짜는 선택기를 열 때마다 새로 계산합니다.

"값 없음"은 비워 둔 속성과도 일치합니다. "같지 않음"이나 "포함 안 함" 같은 부정 조건은 긍정 조건과 일치하지 않는 모든 노트와 일치하며, 그 속성이 없는 노트도 포함합니다.

### 속성 페이지

속성 페이지에는 "활성화"와 "레이블" 그룹이 있습니다. "레이블"에는 목록 페이지와 같은 "접두사"와, "여러 속성" 모드에서는 행의 "이름"이 들어갑니다. 그다음 "모드"는 기본값인 "속성 하나" 또는 "여러 속성"입니다. "속성 하나" 모드에서는 이어서 "속성"과 "유형"이 있습니다. "속성"은 보관함의 속성을 유형과 함께 제안하며, 하나를 고르면 유형도 그에 맞게 설정됩니다. 체크박스, 숫자, 날짜, 날짜 및 시간은 그대로 유지되고, 목록과 태그는 링크 목록이 되며, 나머지는 텍스트가 됩니다. "유형"은 체크박스, 텍스트, 숫자, 날짜, 날짜 및 시간, 노트 하나를 위한 링크, 여러 노트를 위한 링크 목록 중에서 고를 수 있고, 속성을 고르기 전까지는 비활성화되어 있습니다.

![people 링크 목록 속성의 페이지. 다른 행 하나와 공유하는 접두사 칩, 링크 목록 타입의 people 속성, Person으로 링크하는 노트 중에서 제공하는 노트 설정이 있습니다](docs/images/settings-property.png)

모든 속성에는 "비면 삭제"가 있습니다. 기본으로 켜져 있으며, 값을 지우거나 마지막 링크를 제거하면 노트에서 속성을 삭제합니다. 끄면 속성이 빈 값으로 노트에 남습니다.

텍스트나 숫자 속성에는 "미리 설정된 값"도 있습니다. 속성 자체의 선택기가 가장 먼저 제공하는 값의 목록으로, 예를 들어 `status` 속성의 `todo`, `doing`, `done` 같은 값입니다. 머리글의 `+`는 값을 입력하는 텍스트 칸과 스위치가 있는 행을 추가하고, 행은 선택기에 표시될 순서대로 끌어 옮길 수 있으며, 각 행은 삭제할 수 있습니다. 숫자 속성은 숫자로 쓴 값만 유지합니다. 미리 설정된 값은 제한이 아니라 도우미입니다. 선택기는 그 뒤에도 보관함에서 이 속성이 이미 가진 다른 값을 많이 쓰인 순서로 보여 주고, 입력한 내용도 받아들입니다. 미리 설정된 값 옆의 스위치를 켜면 속성 설정 기본 메뉴에도 표시되므로, 미리 설정된 값은 많이 두되 가장 자주 쓰는 몇 개만 한 번에 고를 수 있게 할 수 있습니다. 속성 자체의 선택기에는 미리 설정된 값이 항상 모두 표시됩니다.

링크 또는 링크 목록 속성에는 섹션이 두 개 더 있습니다.

- "노트 가져올 곳"은 선택기가 제공할 노트를 정하며, 이동 목록과 같은 소스를 쓸 수 있습니다.
- "제외 폴더"는 노트를 절대 제공하지 않을 폴더를 나열합니다. 머리글의 `+`로 폴더를 추가하고, 각 행은 삭제할 수 있으며, 빈 행은 아무것도 제외하지 않습니다.

"여러 속성" 모드의 행은 페이지에서 고정한 값으로 여러 속성을 한꺼번에 쓰며, 속성 설정 선택기에서는 하나의 선택지로 나옵니다. 모드를 "속성 하나"로 되돌리면 속성 하나의 설정이 돌아오고, 고정한 값은 다음에 바꿀 때를 위해 저장된 채로 남습니다. "이름"은 선택기에서 이 행에 표시되는 이름이며, 비어 있으면 값 요약이 표시되고 이 요약은 칸의 자리 표시자로도 쓰입니다. "설정할 값"에는 속성마다 블록이 하나씩 있습니다. 머리글의 `+`로 블록을 추가하고, 블록은 끌어서 옮기거나 복제하거나 삭제할 수 있습니다. 각 블록은 `status done`, `archived ✓`, `active 지움`처럼 속성과 값을 보여 주며, 클릭하면 편집기가 열립니다.

- "속성"은 쓸 속성입니다. 포커스를 두면 보관함의 속성이 나열되고, 하나를 고르면 유형도 그에 맞게 설정됩니다. 새 이름도 쓸 수 있습니다.
- "유형"은 체크박스, 텍스트, 숫자, 날짜, 날짜 및 시간, 노트 하나를 위한 링크, 여러 노트를 위한 링크 목록, "지우기 (속성 제거)" 중에서 고릅니다.
- "값"은 체크박스라면 스위치, 텍스트, 숫자, 오늘 또는 고정 날짜, 지금 또는 고정 날짜와 시간, 링크와 링크 목록이라면 노트입니다. 지우기에는 값이 없습니다.

링크 값은 속성에 있는 노트를 바꾸고, 링크 목록 값은 그 노트를 목록에 추가합니다. 속성이나 값이 없는 블록은 건너뜁니다.

기본값의 소스가 서로 다른 `related` 행들처럼 여러 행이 같은 속성에 값을 쓸 수도 있습니다. 이 행들은 하나의 값을 공유하고, 처음 활성화된 "속성 하나" 모드의 행이 유형을 정합니다. 한 속성에 대한 두 행의 유형이 다르면 행에 경고가 표시됩니다.

### 체크박스 동작

속성 페이지의 목록 아래에 있는 "체크박스 동작"은 속성 설정 기본 메뉴에서 체크박스 속성을 골랐을 때 어떻게 동작할지를 모든 체크박스 속성에 대해 정합니다. 선택지는 기본값인 "true, false, 지우기가 있는 선택기 열기", "true와 값 없음 사이에서 전환", "true, false, 값 없음 순서로 순환"입니다. 0.6.1이나 0.6.2에서 속성별로 고른 모드는 이 설정으로 바뀝니다.

### 모든 설정 초기화

기본 페이지 맨 아래의 "모든 설정 초기화"는 모든 목록, 속성, 양식, 옵션을 기본값으로 되돌립니다. 기본값에는 양식이 없습니다. 먼저 확인을 묻고, 취소나 Escape를 누르면 모든 것이 그대로 남습니다. 초기화는 되돌릴 수 없습니다.

초기화는 작업 명령도 삭제합니다. 기본값에는 작업 명령이 없습니다.

## 언어

Note Compass는 Obsidian에서 고른 언어를 따릅니다. 영어, 스페인어, 중국어 간체, 중국어 번체, 일본어, 한국어를 지원하며, 그 밖의 언어에서는 영어로 표시됩니다. 설정, 속성 이름, 노트에 쓰는 값은 언어와 상관없이 입력한 그대로 유지됩니다.

번역은 `src/i18n/`에 있으며, 이 설명서도 맨 위의 링크에서 각 언어로 볼 수 있습니다. 둘 다 기계 번역으로 작성된 초안이라 어색한 표현이 있을 수 있으며, 기준은 영어 설명서입니다. 수정은 풀 리퀘스트로 환영합니다. 언어를 추가하려면 그 폴더에 새 파일 하나를 만들고 등록 파일에 한 줄을 추가하면 되며, 아직 번역되지 않은 텍스트는 영어로 표시됩니다.

## 팁

- 각 명령어에 보지 않고도 누를 수 있는 단축키를 지정하세요. 이 플러그인은 선택기를 열고, 몇 글자 입력하고, Enter를 누르는 흐름을 중심으로 만들어졌습니다.
- 접두사는 `👤 peop`이나 `📅 due`처럼 이모지와 서너 글자짜리 태그 정도로 짧게 두세요. 모든 칩이 가장 넓은 칩의 너비를 따르므로, 긴 접두사 하나가 모든 이름을 오른쪽으로 밀어냅니다.
- 색상으로 관련 목록을 묶으세요. 예를 들어 사람과 회사 목록에는 한 색을, 프로젝트 목록에는 다른 색을 쓰면 한눈에 구분할 수 있습니다.
- 접두사 태그를 입력해 선택기를 한 목록으로 좁히세요. 예를 들어 "속성 설정"에서 `peop`을 입력하면 people 행만 남습니다.
- "노트로 링크" 소스를 가벼운 태그처럼 쓰세요. `Person` 같은 노트를 만들고 people 속성이 "노트로 링크: Person"을 가리키게 합니다. 사람 노트를 만드는 양식의 내용에 `[[Person]]`을 넣어 두면, 새로 만든 사람이 모두 직접 태그를 달지 않아도 목록에 나타납니다.
- 모든 링크 속성의 "제외 폴더"에 템플릿 폴더를 추가해, 템플릿 노트가 값으로 제공되지 않게 하세요.
- "속성 설정"에서 값 선택기의 Escape는 기본 선택기로 한 단계 돌아갈 뿐입니다. 이미 한 변경은 "저장 후 닫기"나 "취소"를 고를 때까지 유지됩니다.
- 작업 명령에서 자주 쓰는 동작을 "키 설정"에 지정하고 키 하나는 비워 두세요. 그 키와 ⚙로 모든 동작을 볼 수 있습니다. "일괄 모드"가 켜져 있다면 Cmd+Enter를 `🏁 처리 끝내기`에 지정해 마지막 행까지 내려가지 않고 저장할 수 있습니다.

## 알려진 동작

- `YYYY/MM/DD`처럼 `/`가 들어간 일 형식은 노트 이름을 폴더 없이 비교하기 때문에 절대 일치하지 않습니다.
- 기본 형식에서는 날짜 노트 폴더에 연도 이름으로 된 노트, 예를 들어 `on/2024`가 연 노트로 취급됩니다. 그 폴더에 그런 이름의 다른 노트를 둔다면 사용자 지정 형식에서 연 기간을 끄세요.
- 속성의 유형이 바뀌면 그 속성에 대한 필터 조건은 예전 조건을 유지한 채, 새 조건을 고를 때까지 아무것과도 일치하지 않습니다. 조건, 해당 목록의 행, 그 페이지에 조건이 더 이상 적용되지 않는다고 표시됩니다.
- 여러 노트에 걸친 쓰기는 원자적이지 않습니다. 실패하면 일부 노트만 바뀔 수 있습니다.
- 복사는 기존 접미사와 블록 ID를 포함한 행 텍스트를 유지합니다. 블록 ID는 새로 생성되지 않고 중복됩니다.

## 개발

```bash
npm ci
npm run dev
npm run build
npm test
npm run lint
```

`npm run dev`는 변경할 때마다 다시 빌드하고, `npm run build`는 타입 검사 후 프로덕션 번들을 만들며, `npm test`는 단위 테스트를 실행하고, `npm run lint`는 커뮤니티 심사에서 쓰는 것과 같은 Obsidian 린트 규칙을 실행합니다.

테스트 보관함에서 플러그인을 써 보려면 저장소를 보관함의 plugins 폴더에 심볼릭 링크로 연결하세요. 그러면 보관함이 항상 `npm run dev`가 방금 만든 빌드를 불러옵니다.

```bash
ln -s "$PWD" "<vault>/.obsidian/plugins/note-compass"
```
