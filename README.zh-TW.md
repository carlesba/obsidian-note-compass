Note Compass 提供用於跳至筆記、編輯屬性、填寫表單及執行自訂任務命令的選擇器。

![「設定屬性」選擇器：最上方是「儲存並關閉」與「取消」，筆記目前的值以勾號標示，下方是更多可新增的值](docs/images/set-properties.png)

## 安裝

Note Compass 上架社群外掛程式瀏覽器後，開啟「設定 → 第三方外掛程式 → 社群外掛程式 → 瀏覽」，搜尋「Note Compass」，安裝並啟用即可。

若要手動安裝，請從 GitHub 最新版本下載 `main.js`、`manifest.json` 與 `styles.css`：

https://github.com/carlesba/obsidian-note-compass/releases/latest

將這三個檔案放進 `<vault>/.obsidian/plugins/note-compass/`，重新載入 Obsidian，然後在「設定 → 第三方外掛程式」中啟用 Note Compass。

Note Compass 需要 Obsidian 1.13.0 或更新版本，桌面版與行動版皆可使用。

## 快速上手

這些命令是設計給鍵盤操作的，所以請先為每個命令設定快速鍵。開啟「設定 → 快速鍵」，搜尋「Note Compass」，為「導覽：預設」、「設定屬性」和「填寫表單」指定按鍵。你也可以從命令面板執行它們。

典型的使用流程如下。打開今天的每日筆記，按下「導覽：預設」的快速鍵，就能移到昨天的筆記，或移到你從今天筆記連結出去的筆記。在正在處理的筆記上按下「設定屬性」的快速鍵，輸入某人名字的幾個字母，選取他，再選擇「儲存並關閉」。對於經常建立的筆記，例如人物，可以在「設定 → Note Compass → 表單」中新增一個表單。

預設設定在「預設」導覽選擇器中提供四個關聯清單，並在「設定屬性」中提供一組常用的核取方塊與連結屬性。開啟「設定 → Note Compass」，可以關閉用不到的項目，並讓連結屬性指向你自己的資料夾與筆記。

在設定 → Note Compass → 任務新增命令，開啟有未完成任務的筆記，執行「處理未完成的任務」。Enter 暫存完成動作，`🏁 結束處理` 儲存。

## 跳至筆記

「跳至筆記」會開啟一個選擇器，列出可前往的筆記。選取一列會在目前分頁開啟該筆記；若沒有開啟任何分頁，則在新分頁開啟。

你可以在 設定 → Note Compass → 導覽 中建立多個具名的導覽選擇器，每個都有自己的清單。每個選擇器在命令面板中顯示為「導覽：<名稱>」，因此可以個別設定快捷鍵。新安裝時只有一個名為「預設」的選擇器，導覽選擇器推出前儲存的清單會原樣移入其中。「跳至筆記」會詢問「開啟哪個導覽選擇器？」，列出所有開啟的選擇器，並開啟你選取的那個。

![在每日筆記上開啟的「跳至筆記」選擇器，列出前一天與後一天、它的對外連結、一則同一天的筆記、本週、本月與今年、進行中的專案以及人物](docs/images/jump-to-note.png)

每個選擇器會依你設定的順序，顯示你在設定中它的頁面上建立的清單。其中有四種清單取決於目前聚焦的 Markdown 筆記；當焦點在其他地方或沒有開啟任何分頁時，這些清單就不會出現：

- 相鄰日期：依每個期間列出目前筆記前後緊鄰的日期筆記：前一天與後一天、上一週與下一週、上個月與下個月、上一季與下一季、前一年與後一年，例如 `📅 day 2024-03-06 (後一天 - 星期三)` 或 `📅 day 2024-W09 (上一週 - 第 9 週)`。比目前筆記短的期間會略過，所以週筆記不會列出天。在清單頁面選擇要列出哪些項目、依什麼順序，以及是否提供尚未存在的筆記。
- 對外連結：列出目前筆記所連結的筆記，包括屬性中的連結。
- 對內連結：列出連結到目前筆記的筆記。
- 同一天：列出與目前筆記在同一天建立的筆記。若目前筆記是日筆記，則以其名稱中的日期為準，而不是檔案的建立時間。

其他清單則與目前筆記無關：

- 過濾：列出符合一組條件的筆記，例如 `status is active`、帶有 `#project` 標籤的筆記，或 `work` 資料夾中最近一週修改過的筆記。條件可以分組，詳見「清單頁面」。
- 連結到筆記：列出在內文或屬性中連結到指定筆記的筆記。
- 資料夾內：列出某個資料夾及其子資料夾中的筆記。
- 今天修改：列出從午夜以來有變更的筆記。
- 目前的日期筆記：列出今天、本週、本月、本季與今年的日期筆記，只包含你開啟的期間。它們依清單頁面設定的順序排列（預設從今天到今年），不依名稱排序，每一列也會標示所屬期間，例如 `本週 - 第 10 週`。除非關閉「顯示尚未存在的筆記」，尚未存在的筆記會顯示為 `建立本週`，選取後會用你的日期筆記外掛程式的方式和相同模板建立並開啟它：Periodic Notes，或者對「日」而言是核心的每日筆記。來自「自訂」格式的期間則以空白筆記開始。若連結屬性使用這個來源，只會提供已經存在的筆記。

一則筆記會出現在每個包含它的清單底下，依你的清單順序排列，而目前筆記本身不會列出。同一個清單內的筆記依名稱排序。如果所有清單都沒有筆記，命令會顯示「沒有可跳至的筆記。」，而不會開啟空白的選擇器。

每一列開頭都有所屬清單的前綴，以小標籤顯示，與名稱區隔開來。同一個選擇器中所有標籤的寬度都與最寬的那個相同（最多約十二個字元），讓名稱對齊；若清單設定了前綴顏色，它的標籤也會套上該顏色。日期筆記會在名稱後加上所屬期間：日筆記顯示星期幾，週筆記顯示 `第 N 週`，月筆記顯示 `月 - <月份>`，年筆記顯示 `年`。

若要在不開啟筆記的情況下編輯它的屬性，請在該列按 ⌥↵（Alt+Enter），或點一下列尾的滑桿圖示。桌面版只在反白的那一列顯示這個圖示，手機上則每一列都有。兩種方式都會針對那則筆記（而非目前筆記）開啟「設定屬性」。會建立缺少的日期筆記的列沒有這個圖示。在這個「設定屬性」中按 Esc、`🛑 取消` 或 `🏁 儲存並返回清單`，都會帶著你剛才輸入的內容回到跳轉清單，方便連續編輯多則筆記。

輸入文字會依順序比對來過濾各列：只要你輸入的字元依相同順序出現在該列中（不分大小寫，中間可以夾雜其他字元），該列就會保留。前綴也是列的一部分，所以輸入前綴的一部分，就能把選擇器縮小到那個清單。

### 日期筆記

當一則筆記直接位於該期間所設定的資料夾中，而且名稱完全符合該期間的格式，它就是日期筆記。期間共有五種：日、週、月、季、年，每一種都有自己的資料夾、格式和開關。

設定主頁面上的「日期筆記來源」設定決定這些格式從哪裡來。「自動」會在 Periodic Notes 外掛程式啟用時使用它，否則使用核心的每日筆記外掛程式，再否則使用本外掛程式自己的「自訂」格式。每日筆記只涵蓋「日」，所以其他期間來自「自訂」。只要有期間來自「自訂」，「日期筆記來源」旁就會出現一支鉛筆，點開即可編輯格式，為每個期間設定資料夾以及 Moment 格式：

https://momentjs.com/docs/#/displaying/format/

預設情況下，所有期間都放在 `on/`，名稱分別如 `2024-03-05`、`2024-W10`、`2024-03` 和 `2024`；季（例如 `2024-Q1`）則預設關閉。

## 設定屬性

「設定屬性」讓你在一個選擇器中編輯目前聚焦的 Markdown 筆記的屬性。只有在 Markdown 筆記取得焦點時，它才會出現在命令面板中。

在選擇器中操作時不會寫入任何內容。最上面兩列固定是 `🏁 儲存並關閉`（只寫入你變更過的屬性）以及 `🛑 取消`（捨棄所有變更）。按 Esc 等同於「取消」。在任何地方（包括屬性自己的選擇器）按 ⌘↵，或在 Windows 與 Linux 上按 Ctrl+Enter，都會儲存目前的內容並關閉選擇器。

接著是筆記儲存時將會帶有的值，每個都以 `✓` 標示：每則已連結的筆記一列，每個核取方塊、文字、數字或日期也各一列，旁邊顯示它的值。在這次操作中變更過的值還會另外標示 `•`。選取已設定的連結會將它移除，因此多連結屬性會少掉那一則筆記。選取已設定的文字、數字或日期會開啟它自己的選擇器；選取已設定的核取方塊則依「核取方塊行為」設定執行。

在已設定的值下方，每個啟用的屬性會依你設定的順序，提供它可以新增的內容：

- 連結或多連結屬性會列出其來源中尚未設定的筆記，最近修改的排在最前面。選取一則會把它加入多連結屬性，或取代單一連結屬性目前的筆記。連結會以清單形式儲存，例如 `["[[Alice]]", "[[Bob]]"]`；屬性中原有、但來源不提供的連結會保留下來。
- 尚未設定的文字、數字、日期或日期時間屬性會顯示一列屬性名稱，選取後開啟它自己的選擇器。儲存庫中已有的值會在那裡提供，而不是在這裡。
- 文字或數字屬性也會在這裡列出「顯示於主選單」開關已開啟的預設值，選一次就能設定。
- 當你輸入的內容不是這些預設值之一時，文字屬性也會提供 `✏️ <屬性>：使用「<輸入的內容>」`。
- 尚未設定的核取方塊會顯示一列屬性名稱，預設會開啟它自己的選擇器。若設為「在 true 與未設定之間切換」，選取它會設為 `true`，在它為 `true` 時再次選取則會清除。若設為「依序切換 true、false 與未設定」，每次選取會前進一步：從未設定到 `true`，再到 `false`，再回到未設定。

在沒有輸入任何文字時，每個屬性最多顯示五個值，後面接著 `… 還有 N 項，輸入以過濾`，選取它會自動幫你輸入該屬性的前綴。一旦開始輸入，所有符合的列都會顯示。選好一個值之後，選擇器會清空過濾並重新開啟，因此 `🏁 儲存並關閉` 又回到最上方，而你剛選的值會顯示在它下方，成為已設定的值。

![輸入「joan」後的「設定屬性」：Joan Puig 已設定並標示為已變更，status 屬性則提供將「joan」作為新值](docs/images/set-properties-search.png)

「多個屬性」模式的列只要一次選擇就能設定多個屬性，例如 `status: done`、`archived: true` 並移除 `active`。它的值在其屬性頁面中固定，因此選擇器從不詢問。該列在選擇器中是一個選項，顯示為它的「名稱」；名稱為空白時則顯示其值的摘要，例如 `status done, archived ✓, active 已清除`，其中屬性以一般顏色顯示，值則顯示為灰色。只要筆記還沒有全部這些值，該列就會出現在可新增的項目中，選取它會一次套用所有值，並重新開啟選擇器、清除篩選。筆記具備全部的值之後，該列會出現在已設定的值中並標示 `✓`；若開啟選擇器時尚未具備，還會標示 `•`。此時選取它不會變更任何內容。多個連結的值會新增其筆記並保留其他連結，連結的值會取代筆記，已清除的值則會移除該屬性。今天和現在會在開啟選擇器時決定。該列不是全部成立就是不成立：只有所有值都成立時才算已設定，而且在儲存之前不會寫入任何內容。

屬性自己的選擇器會以 `✓` 標示目前的值，最後一列是 `🗑️ 清除`，它會移除該屬性；若「空白時移除」已關閉，則會把屬性留空。按 Esc 會回到主選擇器而不變更該屬性，你先前在主選擇器做的變更也都會保留。

- 核取方塊提供 `true` 與 `false`。
- 文字提供 `✏️ 使用「<輸入的內容>」` 作為新值，接著是它的預設值，再來是該屬性在儲存庫中已有的其他值，依使用次數由多到少排列，並顯示各自的使用次數。
- 數字提供 `✏️ 使用「<輸入的內容>」` 作為數字，接著是它的預設值，再來是該屬性在儲存庫中已有的其他數字，依使用次數由多到少排列。
- 日期會為以 `YYYYMMDD` 或 `YYYY-MM-DD` 輸入的日期提供「使用」，接著是「今天」、「明天」、「下週一」和「一週後」，並以 `YYYY-MM-DD` 儲存。
- 日期時間會為 `YYYYMMDDHHmm`、`YYYYMMDD HHmm`、`YYYY-MM-DD HH:mm` 或 `YYYY-MM-DDTHH:mm` 提供「使用」，接著是「現在」，並以 `YYYY-MM-DDTHH:mm` 儲存。

![日期屬性的值選擇器，提供今天、明天、下週一、一週後與清除](docs/images/set-properties-date.png)

連結屬性永遠不會提供目前筆記，或位於該屬性排除資料夾中的筆記。若要隱藏已封存等筆記，請使用篩選來源，在「下列無一條件為真」群組中加入 `archived 為 true`。選擇器只能連結已存在的筆記，所以若要連結新筆記，請先用表單建立它。

## 表單

表單會透過幾個問題建立一則新筆記，例如詢問書名與作者的閱讀紀錄，或詢問主題與參與者的會議筆記。表單在「設定 → Note Compass → 表單」中定義。「填寫表單」會列出你啟用的表單，並執行你選取的那一個；每個啟用的表單本身也是一個以表單名稱命名的命令，因此可以為它設定快速鍵。和其他命令一樣，不論有沒有聚焦的筆記都能使用。沒有表單時，「填寫表單」會顯示「尚無表單。請在「設定 → Note Compass → 表單」中新增。」

表單會為每個詢問欄位提出一個問題，順序依照它的「欄位」清單。按 Esc 會回到上一個問題，在第一個問題按 Esc 則會關閉表單，不建立筆記。返回時，你已經填好的答案會保留，並標上勾號。

最後一個問題之後會開啟摘要。第一列是 `✅ 建立「<名稱>」`，其中是依你的答案算出的筆記名稱；接著每個欄位一列，顯示它將得到的值或 `已略過`；最後是 `🛑 取消`。選取一個詢問欄位會重新開啟它的問題，回答後回到摘要；在摘要按 Esc 會回到最後一個問題，若表單沒有任何問題，則會關閉表單。所有必填問題都有答案後，在任何問題按 ⌘↵，或在 Windows 與 Linux 上按 Ctrl+Enter，都會建立筆記。

筆記會放在表單的「資料夾」中；留空時，則放在 Obsidian 存放新筆記的位置。若那裡已有同名的筆記（不分大小寫），新筆記會加上編號，例如 `Dune 2`。系統會先寫入筆記內文，再依欄位順序寫入屬性。接著 Note Compass 會告訴你筆記的位置，例如 `已在 reading 建立「Dune」。`，並開啟它，除非關閉了「建立後開啟筆記」。

### 表單頁面

表單的頁面包含：

- 「啟用」：在「填寫表單」中提供此表單，並作為命令提供。
- 「名稱」：顯示於「填寫表單」中，並作為命令名稱。
- 「筆記名稱」：新筆記名稱的樣式，例如 `{{date:YYMMDDHHmm}} {{book}}`。空的預留位置造成的重複空格會合併為一個；名稱若最後是空的，或含有 Obsidian 無法用於檔案名稱的字元，就會被拒絕並顯示訊息，你會停留在摘要。
- 「筆記內容」：新筆記的內文，可使用相同的預留位置。
- 「資料夾」：新筆記存放的位置。
- 「建立後開啟筆記」：預設開啟。
- 「欄位」：表單填入或詢問的值。它們的順序就是問題的順序。

欄位清單的操作方式和設定中的其他清單相同：拖曳把手可重新排序，複製圖示可在正下方複製欄位，叉號可刪除欄位，標題中的 `+` 可新增欄位。`+` 會開啟一個選單：「空白欄位」會新增一個空的詢問文字欄位，而「日期」「時間」「時間戳記」和「ISO 時間戳記」會新增一個在建立時取值的固定欄位，鍵為 `date`、`time`、`timestamp` 或 `iso-timestamp`，格式為 `YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm` 或 ISO 8601。每個項目都會顯示它此刻會寫入的內容，已被使用的鍵會加上編號，例如 `timestamp-2`。「確認條目日期」和「確認條目時間」會新增詢問變數 `entry-date` 和 `entry-time`，兩者可同時使用。

日期輸入 `YYYYMMDD`，時間輸入 `HHmm`，皆為文字。下方選項預覽完整的 `YYYY-MM-DD HH:mm`，按 Enter 保留顯示值。變更日期保留時間，變更時間保留日期，在最終檢查中重新編輯也一樣。合併的日期時間用於 `{{date}}`、`{{time}}`、筆記名稱及「建立時」的固定欄位。現有設定繼續保留，日期時間類型仍變更完整時間戳記。只有多個欄位變更同一部分時才會警告。每一列會顯示欄位的鍵，後面接著標示儲存位置、模式和類型的小徽章，例如 `book` `變數` `詢問` `文字`。屬性徽章為藍色，變數徽章為紫色。點選該列或它的箭頭，即可在正下方編輯欄位，再點一次則收合。一次只會展開一個欄位，新欄位會直接展開。

名稱、內容、固定的文字值與清單項目支援以下預留位置：

- `{{date}}` 和 `{{time}}` 是表單開始的時間，格式依核心「模板」外掛程式的設定。`{{date:FORMAT}}` 和 `{{time:FORMAT}}` 使用指定的格式。
- `{{key}}` 是名為 `key` 的欄位的值。清單會以逗號連接，略過的欄位則為空。
- `{{key:FORMAT}}` 以指定的格式呈現日期或時間欄位，例如 `{{started:dddd}}`。
- `{{title}}` 只用於內容，代表新筆記的名稱。
- `{{today}}`、`{{tomorrow}}` 和 `{{yesterday}}` 是條目日期、次日和前一日，採用 Date notes 來源的日記格式，沒有格式時為 `YYYY-MM-DD`。`{{today:FORMAT}}` 使用指定的格式；名為 `today` 的欄位優先於預留位置。
- 放在連結裡的預留位置，如 `[[{{today}}]]`，會連結到它所指的筆記，變成 `[[2026-10-31]]`。

其他預留位置會保持原樣。

在這些輸入框中，於開頭或空格、`[`、`(` 之後輸入 `@` 會開啟表單已知預留位置的選單，並依 `@` 後輸入的內容篩選：附有目前日期預覽的 `today`、`tomorrow` 和 `yesterday`，表單的每個鍵（包括條件區塊中的欄位），`date`、`time`，以及內容中的 `title`。每一項有兩種形式：原樣的 `today` 和連結形式的 `[[today]]`。選取一項後，`@` 和已輸入的內容會被替換為一個膠囊。膠囊是一個整體，游標會跳過它，Backspace 或 Delete 會整個刪除。Escape 關閉選單並保留已輸入的文字。手動輸入或貼上的預留位置（如 `{{book}}`）同樣顯示為膠囊，`[[{{book}}]]` 顯示為一個連結膠囊；表單中沒有的鍵以虛線邊框顯示並保持原樣。設定中儲存的是含 `{{…}}` 的純文字，膠囊只是輸入框的顯示方式。

### 欄位

每個欄位都有「鍵」、「儲存為」、「填寫方」，詢問欄位還有「問題」，接著是「資料類型」，詢問的文字、數字與清單還有「來源」。「鍵」是屬性名稱或變數名稱，兩種情況都以 `{{key}}` 使用。「儲存為」可以是「屬性」（預設），把值以它的鍵寫入新筆記的屬性；或是「變數」，它的值只用來填入名稱與內容中的預留位置，永遠不會寫入。「填寫方」為「固定值」或「提問」。「資料類型」是寫入的值的類型：文字、數字、核取方塊、清單、日期、時間或日期 & 時間。「來源」是答案從哪裡來：「手動輸入」「固定選項」或「筆記」。

固定欄位可以是文字、數字、核取方塊、清單、日期、時間或日期 & 時間。數字只會保留數字，核取方塊則是一個開關。清單有一個輸入框，每個項目都會顯示為一個標籤：輸入一個項目後按 Enter 即可新增，用它的 × 移除。項目可以是連結，因此 `[[Books]]` 和 `[[Reading]]` 會寫入 `categories: ["[[Books]]", "[[Reading]]"]`，表單就是這樣把它的筆記連結到其他筆記。在固定的文字值或清單的輸入框中輸入 `[[` 會建議儲存庫中的筆記，選取一則就會寫入它的連結，例如 `[[Books]]`，只有兩則筆記同名時才會加上資料夾。在清單的輸入框中，選取的連結會立刻變成一個標籤。固定的文字值與清單的每個項目也可以用與筆記名稱相同的預留位置，由表單的其他欄位和日期組合而成，欄位順序無關：項目為 `[[today]]` 的 `dates` 清單寫入 `dates: ["[[2026-10-31]]"]`，把新筆記連結到今天的日記；內容為 `{{book}} rated {{rating}}` 的 `summary` 文字寫入 `Dune rated 4`。因所用欄位被略過而變為空或 `[[]]` 的項目會被捨棄，變為空的文字不會寫入，條件區塊的條件依組合後的值比較。

詢問欄位可以是文字、數字、核取方塊、清單、日期、時間或日期 & 時間。「問題」是提示文字，留空時使用欄位的鍵。「選填」會在問題最前面放上 `⏭️ 略過`；略過的屬性完全不會寫入，略過的變數則為空。預設來源「手動輸入」下，文字或數字問題接受你輸入的任何內容，屬性還會提供它在儲存庫中已有的值；清單逐一加入你輸入或選取的項目（標上勾號），以 `🏁 完成` 結束。核取方塊、日期與時間沒有來源。

「固定選項」會顯示一個「選項」清單，每個選項都有一個值與一個可省略的標籤。「選項」標題中的 `+` 可新增選項，叉號可移除選項，拖曳選項的把手可重新排序。問題中會顯示標籤，沒有標籤時則顯示值，筆記得到的是值：數字欄位把值寫成數字，因此值為 `4`、標籤為 `4 · 很棒` 的選項會寫入數字 4；清單把選取的值寫成項目。值可以包含以 `@` 輸入的預留位置，例如 `[[{{today}}]]`，在執行表單時填入。「筆記」提供「筆記來源」中的筆記，來源的選法與「跳轉到筆記」的清單相同：一個篩選器、連結到某則筆記的筆記、某個資料夾中的筆記、今天修改的筆記，或目前筆記連出的、連入的或同一天的筆記。筆記得到所選筆記的連結，例如 `[[Dune]]`；文字寫入一個連結，清單寫入所有選取筆記的連結。在名稱與內容中，`{{key}}` 是不含方括號的筆記名稱，`[[{{key}}]]` 則連結到它。把資料類型改成不支援目前來源的類型時，來源會重設為「手動輸入」。

日期、時間與日期 & 時間欄位有「格式」：`YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm`、ISO 8601，或自訂的 Moment.js 格式。固定欄位的「值」取自「建立時」，也就是表單開始的時間；取自「指定日期」，也就是你在下方輸入的日期；或取自「取自欄位 …」，也就是表單中另一個日期或時間欄位的值。指定日期以數字輸入，日期為 `YYYYMMDD`，時間為 `HHmm`，日期 & 時間為 `YYYYMMDDHHmm`，也可以加上連字號和冒號，下方的一行會顯示讀取的結果，例如 `✓ Mon 30 Oct 2028, 09:00`。如此一來，一個詢問的時間就能填入多個屬性，例如格式為 `YYYY-MM-DD` 的 `day` 與格式為 ISO 8601 的 `timestamp`。若來源欄位被略過，它也會被略過。詢問欄位會提供「現在」，日期還會提供「今天」、「明天」、「下週一」和「一週後」。你也可以輸入 `20240311`、`2024-03-11`、`0930`、`09:30`、`202403110930` 或 `20240311 0930`，和「設定屬性」的日期選擇器一樣。時間指的是今天的那個時間。

區塊把只在前面的回答相符時才使用的欄位歸在一起，例如只在筆記是關於一本書時才詢問頁數。「欄位」標題的 `+` 選單中的「條件區塊」會在清單末尾新增一個空區塊，區塊底部的 `+` 會在其中新增欄位。把欄位拖到區塊標題和底部列之間即可放進區塊，拖出去則回到清單。拖曳區塊標題會移動整個區塊，區塊不能放進另一個區塊。刪除區塊時，其中的欄位會留在清單中。點一下標題即可編輯條件：每個條件選擇區塊上方的一個欄位、依欄位類型提供的檢查（如「是」「含有項目」「=」「早於」「已設定」），大多數情況下還要選一個值；有固定選項的欄位會把選項當作值提供，日期與時間以 `YYYYMMDD`、`HHmm` 或 `YYYYMMDDHHmm` 輸入。只有所有條件都成立時才會使用該區塊。未使用的區塊不會提問，其欄位不會出現在摘要中、不會寫入，預留位置為空。多個欄位可以使用同一個鍵（例如兩個區塊中各有一個 `categories`）：有值的最後一個欄位生效，略過的欄位不會清除前面欄位的值。

沒有鍵的欄位、沒有任何選項的固定選項、沒有筆記或資料夾的筆記來源，或取自非日期欄位的日期，都會在欄位所在的列和表單上顯示警告。沒有條件或欄位的區塊、缺少欄位或值的條件、針對不在區塊上方欄位的條件，或不適用於該欄位類型的條件，會在區塊所在的列和表單上顯示警告。這個版本的 Note Compass 無法讀取的表單會以關閉狀態留在清單中，顯示警告且沒有鉛筆，就像無法讀取的清單一樣；它儲存的設定會保留，直到你刪除它為止。

## 任務命令

用自己定義的命令面板命令處理目前 Markdown 筆記中的任務。

### 快速上手

在設定 → Note Compass → 任務用 `+` 新增命令並命名。開啟 Markdown 筆記，從命令面板執行該名稱，也可以指定快捷鍵。只有啟用且至少有一個動作的命令才會提供。沒有符合的任務時會顯示通知，而非開啟空選擇器。

無法讀取的命令會保持關閉並顯示警告，直到將其移除。

### 動作

每個動作有「標籤」、一種「動作」和一個字元的「狀態」。用 `+` 新增、拖曳排序、複製圖示複製、× 刪除；點選列可在下方編輯。

#### 變更狀態

變更原任務列的核取方塊字元。「完成日期」可以加入後綴。

| 完成日期 | 加入的文字 |
| --- | --- |
| 關閉 | 無。 |
| 日期 | ` ✅ 2028-10-30` |
| 日期連結 | ` ✅ [[2028-10-30]]` |
| 時間戳記 | ` ✅ 2028-10-30 09:00` |

範例日期使用「日期筆記」的日誌格式，日期是今天，而非原筆記的日期。時間戳記加入核心範本外掛的時間格式。日期連結不會建立筆記。

#### 複製到筆記

將未完成的任務 `[ ]` 附加到另一則筆記末尾，並設定原任務的「狀態」。只複製任務這一列，不複製子任務、接續列、縮排或引用前綴。

- 「目標」開啟獨立頁面：用 `+` 新增、拖曳排序、× 刪除，返回箭頭回到命令。
- 複製任務的前綴和後綴僅原樣加入副本內文，位於區塊 ID 和來源連結之前。請自行包含空格；預設留空，即時和批次處理皆適用。
- 「連結目標筆記」在原任務加入 ` → [[目標]]`；「連結來源筆記」在副本加入 ` ← [[來源]]`。
- 期間相對於今天，而非原筆記日期，使用「日期筆記」中啟用的期間、資料夾與格式。一個可用目標直接執行；多個目標依設定順序開啟「要複製到哪個筆記？」。不提供原筆記與重複目標。
- 不存在的指定筆記會被略過並顯示通知。若沒有剩餘目標，不會變更任何內容。
- 缺少的週期筆記在儲存時建立。如果「日期筆記」使用 Periodic Notes，會先請求該外掛使用範本建立筆記。若 API 無法使用、失敗或未建立預期路徑，則建立空筆記。其他來源，包括核心日誌與自訂，都會先建立空筆記再附加任務。

![「遷移」的「要複製到哪個筆記？」，提供明天、本週、標為新筆記的下週以及本月，每一項都帶有其筆記的名稱](docs/images/task-destinations.png)

### 選擇器與批次模式

![動作選單「要套用哪個動作？」，其中有 ✅ 完成、🚫 取消、➡️ 遷移與 📅 排程](docs/images/task-actions.png)

- 輸入文字按字元順序、不區分大小寫地篩選任務文字。「按鍵」中的按鍵執行綁定的動作；其他按鍵或 ⚙ 開啟所有動作。
- 「全選」在搜尋符合多個任務時新增 `⚡ 套用到全部 N 個任務`。只處理符合搜尋的任務，而非整則筆記。
- 啟用「批次模式」時，每次選擇都會暫存，然後重新開啟選擇器，顯示剩餘任務並清空搜尋。`🏁 結束處理` · N 項變更 儲存所有變更。任務選擇器中的 `🛑 取消` 或 Escape 捨棄所有暫存變更。在動作或目標選擇器按 Escape 只會返回，保留先前暫存的變更。
- 處理最後一個任務會自動儲存並結束。選取 `⚡ 套用到全部 N 個任務` 也會立即儲存並結束，即使搜尋隱藏了其他任務。
- 關閉「批次模式」時，一次選擇立即寫入並關閉選擇器；Escape 無法復原。兩種模式都會略過選擇器開啟後被修改的原任務列，並顯示通知。

### 新命令的預設值

新命令採用 Bullet Journal 設定，名稱為「處理未完成的任務」：啟用，只列出未完成 `[ ]`，不略過任何狀態，「全選」關閉，「批次模式」開啟。「按鍵」把 Enter 綁定到「✅ 完成」，因此 Alt+Enter、Cmd+Enter 和 Shift+Enter 會開啟操作選單。

| 動作 | 原任務狀態 | 其他設定 |
| --- | --- | --- |
| ✅ 完成 | `[x]` | 完成日期：關閉。 |
| 🚫 取消 | `[-]` | 完成日期：關閉。 |
| ➡️ 遷移 | `[>]` | 明天, 本週, 下週, 本月; 只連結目標。 |
| 📅 排程 | `[<]` | 下個月, 下一季, 明年; 連結目標與來源。 |

這些預設目標只適用於新命令，已儲存的目標不變。

### 已知行為
- 跨多則筆記的寫入不是不可分割的操作：失敗時可能只有部分筆記更新。
- 複製保留列文字，包括現有後綴與區塊 ID；區塊 ID 會重複，而非重新產生。

設定頁面在窄視窗中也能正常顯示，行動版的操作方式也相同。主頁面開頭是一段簡短說明，介紹「導覽」、「屬性」、「表單」與「任務」這四個頁面各自包含什麼；接著是這四個頁面、「整合」群組中的「日期筆記來源」，最後是「重設所有設定」。

點一下四列中任一列的任何位置即可開啟它的頁面，用頂端的返回箭頭返回。某一列自己的頁面會在它所屬的區段內開啟，因此從某個清單的頁面返回時會回到它所屬導覽選擇器的頁面，再返回一次則回到「導覽」頁面。該頁面列出你的導覽選擇器，新增、排序、開關、編輯、複製和刪除的操作與其他設定清單相同；每個選擇器有「啟用」「名稱」「過濾」和它的清單。選擇器的過濾在每個清單本身的來源與過濾之外套用至所有清單，只顯示符合的筆記；空白時不會隱藏任何筆記。新選擇器不含清單、過濾為空，複製圖示會連同過濾和所有清單一起複製。

![導覽選擇器的頁面，每個清單顯示為一列，帶有前綴標籤、開關、複製圖示、鉛筆與刪除按鈕](docs/images/settings-jump-to-note.png)

### 表單與任務

使用與其他清單相同的新增、排序、啟用、編輯、複製與刪除控制項。命令頁面包括命令、列出的任務、要略過的任務、選項與動作。新增之前沒有任務命令，新命令採用 Bullet Journal 動作。

表單與任務的列只顯示名稱；第二列僅在有警告時顯示，不再顯示設定摘要。

### 清單與屬性

導覽選擇器的頁面和「屬性」頁面都是由多列組成的清單，各列的操作方式相同。每一列會顯示它的前綴標籤，以及它列出或寫入的內容，例如 `status is active` 或 `people · links`。

- 拖曳左側的把手可重新排列各列。這裡的順序就是選擇器中的順序。
- 使用開關可在選擇器中顯示或隱藏某一列，而不會遺失它的設定。
- 使用鉛筆可開啟該列的頁面，使用叉號可刪除它。
- 使用複製圖示可複製一列。副本會出現在該列正下方，設定相同，表單的副本會命名為 `<名稱> 副本`。
- 使用清單上方的 `+` 可新增一列。新列的頁面會立刻開啟讓你填寫，而且新列預設為開啟。

這個版本的 Note Compass 無法讀取的列（例如由較新版本儲存的列）會留在清單中並顯示警告：「這個版本的 Note Compass 無法讀取此清單。請將它移除並重新建立。」它的開關會關閉並停用，也沒有鉛筆，因此不會為選擇器提供任何筆記；但它儲存的設定會原封不動保留，直到你刪除它為止。

點一下或輕觸前綴標籤，或讓它取得焦點後按 Enter，就會開啟它的選單；在手機上，選單會以底部面板的形式出現。選單會列出所有導覽選擇器和「屬性」頁面中使用中的每個前綴，每個前綴都顯示為它的標籤，後面接著使用它的列數，例如 `📅 due` 標籤後接 `· 3 列`，使用最多的排在前面。該列自己的前綴會打勾。選擇一個前綴，就會把它的文字和顏色套用到這一列，其他列都不會變更。「編輯前綴…」會開啟該列的頁面，並把游標放在「前綴」中；「無前綴」只在該列有前綴時出現，用來清除它的文字和顏色。空白的前綴會顯示為淡色的 `前綴` 標籤，而且不會出現在選單中。

兩列的文字和顏色都相同時，才算共用同一個前綴，所以紅色的 `👤 peop` 和沒有顏色的 `👤 peop` 是兩個前綴。

### 清單頁面

清單頁面有「啟用」和「前綴」，接著是「來源」，用來選擇清單包含哪些筆記：相鄰日期、對外連結、對內連結、同一天、過濾、連結到某則筆記的筆記、資料夾內的筆記、今天修改的筆記，或目前的日期筆記。「相鄰日期」與「目前的日期筆記」會在來源下方多出兩個設定。「顯示尚未存在的筆記」關閉時只列出已存在的日期筆記；開啟時也會列出缺少的筆記，例如 `建立下一週`，選取即可建立。預設上，相鄰日期為關閉，目前的日期筆記為開啟。「要列出的筆記」每個項目一列，預設全部開啟：相鄰日期為「前一天」「後一天」直到「前一年」「後一年」，目前的日期筆記為「今天」到「今年」。拖曳某列的把手可改變選擇器中的顯示順序，關閉某列即可將它排除。缺少的相鄰日期筆記在日期筆記來源為 Periodic Notes 時以其模板建立，其他情況則建立為空白筆記。

![相鄰日期清單頁面，「顯示尚未存在的筆記」為關閉，下方「要列出的筆記」列出前一天、後一天、上一週、下一週等期間，每列都有開關與拖曳把手](docs/images/list-adjacent-dates.png)

在清單或屬性頁面上，「前綴」會顯示設定按鈕、標籤的預覽、它的文字和顏色。你輸入的文字和挑選的顏色會變更這一列，以及開啟頁面時與它共用該前綴的所有列，說明中會列出這些列，例如「另有 2 列使用：people · 多個連結, 對外連結」。即使文字暫時為空白，它們也會保持一致。圓形箭頭可移除顏色。

設定按鈕（「選擇前綴」）會開啟前綴選單。選擇一個前綴會把它的文字和顏色套用到這一列，其他列不會變更。「新增前綴…」會在該列有前綴時出現，並將它清空，因此你接下來輸入和挑選的內容只會變更這一列。「無前綴」會在該列有前綴時出現，並清除其文字和顏色。

過濾的運作方式和外觀都與 Obsidian Bases（資料庫）中的過濾相同。它是一個群組，開頭是「下列全部條件為真」、「下列任一條件為真」或「下列無一條件為真」，分別表示筆記要符合群組中的每一個過濾、至少一個，或一個都不符合，才會被列出。每一列過濾都以它要檢查的對象開頭：輸入屬性名稱，或從建議中選擇 `資料夾`、`標籤`、`連結`、`建立時間` 或 `修改時間`。然後選擇運算子和值，例如 `資料夾 位於 projects`、`標籤 含有標籤 client` 或 `修改時間 晚於 7 天前`。「添加過濾」會在群組中新增一列，「添加過濾群組」則會在其中新增一個有自己條件模式的群組。群組可以層層巢狀，最多三層（包含過濾本身）。列或內層群組上的垃圾桶按鈕可將其移除；移除內層群組的最後一列時，該群組也會一併移除。新的過濾沒有任何列，在你新增之前不會列出任何筆記；過濾中的空白群組不會參與比對。

每個條件都先選擇它要檢查的對象：

- 屬性：依該屬性的類型提供條件來檢查屬性，詳見下方說明。
- 資料夾：以「位於」比對某個資料夾及其子資料夾中的筆記，或以「不位於」比對其他所有筆記。
- 標籤：比對在屬性或內文中帶有某個標籤的筆記。標籤也會比對其子標籤，因此 `project` 會符合 `#project/website`；大小寫和開頭的 `#` 都不影響。「不含標籤」會比對沒有該標籤的筆記。
- 連結到筆記：比對在內文或屬性中連結到指定筆記的筆記；「不包含」則比對沒有連結到它的筆記。
- 建立時間與修改時間：用「在」、「不在」、「早於」或「晚於」，將筆記建立或最後變更的日期與固定日期或相對於今天的日期比較。

清單的列會顯示過濾中唯一的條件，例如 `status is active` 或 `標籤為 project`；或者顯示條件數量，例如 `全部 3 個條件`。

舊版以「Notes with a property」儲存的清單，會以只含該屬性條件的過濾開啟，列出的筆記與以前相同。

屬性條件會先要求選擇屬性（並提示儲存庫中的屬性及其類型），再選擇該類型可用的條件：

- 核取方塊屬性可以為 true、為 false、已設定或未設定。「為 false」需要明確的 `false`。
- 文字屬性可以等於或不等於某個值、包含或不包含它、已設定或未設定。
- 清單、標籤與別名屬性可以含有或不含與該值相等的項目、已設定或未設定。Wiki 連結以連結文字比較，因此 `[[Project]]` 會符合值 `Project`。
- 數字屬性可以等於、不等於、小於或大於某個數字、已設定或未設定。
- 日期屬性可以在、不在、早於或晚於某個固定日期、今天，或若干天前或若干天後，也可以已設定或未設定。相對日期會在每次開啟選擇器時重新計算。

「未設定」也會符合留空的屬性。否定條件（例如「不是」或「不包含」）會符合所有不符合對應肯定條件的筆記，包括沒有該屬性的筆記。

### 屬性頁面

屬性頁面有「啟用」和「標籤」群組，「標籤」中有與清單頁面相同的「前綴」，在「多個屬性」模式下還有該列的「名稱」。接著是「模式」，可以是預設的「單一屬性」或「多個屬性」。在「單一屬性」模式下，後面是「屬性」和「類型」。「屬性」會提示儲存庫中的屬性及其類型，選取其中一個會自動設定相符的類型：核取方塊、數字、日期和日期時間維持原類型，清單和標籤會變成多個連結，其他則變成文字。「類型」可以是核取方塊、文字、數字、日期、日期 & 時間、連結（單一筆記）或多個連結（多則筆記）；在選擇屬性之前會維持停用。

![people 多連結屬性的頁面：它的前綴標籤與另一列共用，people 屬性的類型為多連結，提供的筆記來自連結到 Person 的筆記](docs/images/settings-property.png)

每個屬性都有「空白時移除」，預設為開啟：當你清除它的值或移除最後一個連結時，就會把該屬性從筆記中移除。關閉時，屬性會以空值留在筆記中。

文字或數字屬性還有「預設值」，這是它自己的選擇器會優先提供的一組值，例如 `status` 屬性的 `todo`、`doing` 與 `done`。標題中的 `+` 會新增一列，包含值的文字欄位和一個開關；各列可以拖曳成選擇器顯示的順序，每一列也都可以刪除。數字屬性只保留以數字寫成的值。預設值是輔助而非限制：在預設值之後，選擇器仍會提供該屬性在儲存庫中已有的其他值（依使用次數由多到少），以及你輸入的任何內容。預設值旁的開關也會讓它出現在「設定屬性」主選單中，因此你可以保留許多預設值，只讓最常用的幾個一選即得。每個預設值都一定會出現在該屬性自己的選擇器中。

連結或多連結屬性另外還有兩個區段：

- 「筆記來源」選擇選擇器要提供哪些筆記，可用的來源與跳轉清單相同。
- 「排除的資料夾」列出其中筆記永遠不會被提供的資料夾。標題中的 `+` 可新增資料夾，每一列都可以刪除，空白列不會排除任何東西。

「多個屬性」模式的列會用頁面上固定的值一次寫入多個屬性，「設定屬性」選擇器會把它當成一個選項提供。把模式切回「單一屬性」會恢復單一屬性的設定，固定的值則會保存下來，供下次切換使用。「名稱」是選擇器為該列顯示的內容；空白時會顯示其值的摘要，這個摘要也會作為欄位的預留文字。「要設定的值」中每個屬性一個區塊：標題中的 `+` 可新增一個，區塊可以拖曳、複製和刪除。每個區塊會顯示其屬性和值，例如 `status done`、`archived ✓` 或 `active 已清除`，點擊即可開啟其編輯器。

- 「屬性」是要寫入的屬性。取得焦點時會列出儲存庫中的屬性，選取其中一個會自動設定相符的類型。也可以使用新名稱。
- 「類型」可以是核取方塊、文字、數字、日期、日期 & 時間、連結（單一筆記）、多個連結（多則筆記）或「清除（移除屬性）」。
- 「值」對核取方塊是一個開關，或是一段文字、一個數字、今天或固定日期、現在或固定日期與時間，連結和多個連結則是一則筆記。清除沒有值。

連結的值會取代屬性中已有的筆記，多個連結的值會把其筆記新增到清單中。沒有屬性或沒有值的區塊會被略過。

多個列可以寫入同一個屬性，例如預設的數個 `related` 列各自使用不同來源。它們共用同一個值，類型則由第一個啟用的「單一屬性」模式列決定。當同一個屬性的兩個列類型不一致時，該列會顯示警告。

### 核取方塊行為

「核取方塊行為」位於「屬性」頁面的清單下方，決定在「設定屬性」主選單中選取核取方塊屬性時會發生什麼，適用於所有核取方塊屬性：開啟含有 true、false 與「清除」的選擇器（預設），在 true 與未設定之間切換，或依序切換 true、false 與未設定。在 0.6.1 或 0.6.2 版為單一屬性選擇的模式，會轉為這個設定。

### 重設所有設定

「重設所有設定」位於主頁面最下方，會將所有清單、屬性、表單與選項恢復為預設設定，而預設設定中沒有任何表單。執行前會先詢問，按「取消」或 Esc 則一切維持原狀。重設無法復原。

重設也會刪除任務命令；預設值不包含任務命令。

## 語言

Note Compass 會跟隨你在 Obsidian 中選擇的語言。它提供英文、西班牙文、簡體中文、繁體中文、日文與韓文，其他語言則顯示英文。無論使用哪種語言，你的設定、屬性名稱以及寫入筆記的值都會保持你輸入的樣子。

翻譯檔位於 `src/i18n/`，本手冊也透過頂端的連結提供上述各語言版本。兩者都由機器翻譯初稿，部分措辭可能不太自然，內容以英文手冊為準。歡迎以 pull request 提供修正。新增一種語言只需要在該資料夾中新增一個檔案，並在其註冊表中加入一行；某種語言尚未翻譯的文字會以英文顯示。

## 小技巧

- 為這些命令設定不用看鍵盤也能按到的快速鍵。這個外掛程式的使用方式就是：開啟選擇器、輸入幾個字母、按 Enter。
- 前綴要簡短，例如一個表情符號加上三、四個字母的標記，像是 `👤 peop` 或 `📅 due`。所有標籤的寬度都與最寬的那個相同，所以一個長前綴就會把所有名稱往右推。
- 用顏色為相關的清單分組，例如所有人物與公司清單用一種顏色，專案清單用另一種，一眼就能分辨。
- 輸入前綴標記即可把選擇器縮小到某個清單，例如在「設定屬性」中輸入 `peop` 只看人物相關的列。
- 把「連結到筆記」來源當作輕量的標籤使用。建立一則像 `Person` 這樣的筆記，然後讓人物屬性指向「連結到筆記：Person」。在用來建立人物筆記的表單內容中放入 `[[Person]]`，這樣每個新人物不必手動加標籤就會出現在清單中。
- 在每個連結屬性的「排除的資料夾」中加入你的模板資料夾，這樣模板筆記就永遠不會被當作值提供。
- 在「設定屬性」中，於值選擇器按 Esc 只會退回主選擇器。你已做的變更會一直保留，直到你選擇「儲存並關閉」或「取消」。
- 在任務命令中，把最常用的動作綁定到「按鍵」，並留一個按鍵不綁定：這個按鍵和 ⚙ 仍會開啟所有動作。開啟「批次模式」時，把 Cmd+Enter 綁定到 `🏁 結束處理`，不必捲動到最後一列即可儲存。

## 已知行為

- 含有 `/` 的日格式（例如 `YYYY/MM/DD`）永遠不會符合，因為比對筆記名稱時不包含其所在資料夾。
- 使用預設格式時，日期筆記資料夾中以年份命名的筆記（例如 `on/2024`）會被視為年筆記。如果你在該資料夾中也有以這種方式命名的其他筆記，請在「自訂」格式中關閉「年」期間。
- 如果屬性變更了類型，針對它的過濾條件會保留原本的條件，在你選擇新條件之前不會符合任何筆記。該條件、所屬清單的列以及其頁面都會說明此條件已不再適用。
- 跨多則筆記的寫入不是不可分割的操作：失敗時可能只有部分筆記更新。
- 複製保留列文字，包括現有後綴與區塊 ID；區塊 ID 會重複，而非重新產生。

## 開發

```bash
npm ci
npm run dev
npm run build
npm test
npm run lint
```

`npm run dev` 會在每次變更時重新建置，`npm run build` 會進行型別檢查並輸出正式版套件，`npm test` 會執行單元測試，`npm run lint` 則會執行與社群審查相同的 Obsidian lint 規則。

若要在測試用儲存庫中試用外掛程式，請將此儲存庫以符號連結放入其外掛程式資料夾，這樣儲存庫就會一直載入 `npm run dev` 剛建置好的版本：

```bash
ln -s "$PWD" "<vault>/.obsidian/plugins/note-compass"
```
