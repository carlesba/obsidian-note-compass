# Note Compass

[English](README.md) · [Español](README.es.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

本手册由机器翻译起草，内容以英文版 README 为准。

Note Compass 提供用于跳转笔记、编辑属性、填写表单和运行自定义任务命令的选择器。

![“设置属性”选择器：顶部是“保存并关闭”和“取消”，笔记的当前值带有勾号，下方是可以添加的更多值](docs/images/set-properties.png)

## 安装

Note Compass 上架社区插件市场后，打开 设置 → 第三方插件 → 浏览，搜索“Note Compass”，然后安装并启用。

如需手动安装，请从 GitHub 上的最新版本下载 `main.js`、`manifest.json` 和 `styles.css`：

https://github.com/carlesba/obsidian-note-compass/releases/latest

把这三个文件放到 `<vault>/.obsidian/plugins/note-compass/`，重新加载 Obsidian，然后在 设置 → 第三方插件 中启用 Note Compass。

Note Compass 需要 Obsidian 1.13.0 或更高版本，可在桌面端和移动端运行。

## 快速上手

这些命令是为键盘操作设计的，所以请先为每个命令设置快捷键。打开 设置 → 快捷键，搜索“Note Compass”，为“导航：默认”、“设置属性”和“填写表单”分配按键。你也可以从命令面板运行它们。

典型的用法是这样的：打开今天的日记，按下“导航：默认”的快捷键，就能跳到昨天的笔记，或跳到你在其中链接过的笔记。在正在编辑的笔记上按下“设置属性”的快捷键，输入某个人名字的几个字母，选中这个人，再选择“保存并关闭”。对于经常创建的笔记，例如人物，可以在 设置 → Note Compass → 表单 中添加一个表单。

默认设置在“默认”导航选择器中提供四个关系列表，在“设置属性”中提供一组常用的复选框和链接属性。打开 设置 → Note Compass，可以关闭用不到的部分，并让链接属性指向你自己的文件夹和笔记。

在设置 → Note Compass → 任务中添加命令，打开有未完成任务的笔记，运行“处理未完成的任务”。回车暂存完成操作，`🏁 结束处理` 保存。

## 跳转到笔记

“跳转到笔记”会打开一个选择器，列出可以前往的笔记。选择某一行会在当前标签页中打开该笔记；如果没有打开的标签页，则在新标签页中打开。

你可以在 设置 → Note Compass → 导航 中创建多个具名的导航选择器，每个都有自己的列表。每个选择器在命令面板中显示为“导航：<名称>”，因此可以单独设置快捷键。新安装时只有一个名为“默认”的选择器，导航选择器出现之前保存的列表会原样移入其中。“跳转到笔记”会询问“打开哪个导航选择器？”，列出所有开启的选择器，并打开你选中的那个。

![日记上的“跳转到笔记”选择器，其中有前一天和后一天、它的出链、一篇同一天的笔记、本周、本月和今年、进行中的项目以及人物](docs/images/jump-to-note.png)

每个选择器按你在设置中它的页面上设定的顺序显示各个列表。可用列表中有四个依赖于当前的 Markdown 笔记；当焦点在其他内容上或没有打开的标签页时，它们不会出现：

- 相邻日期：按每个周期列出当前笔记前后紧邻的日期笔记：前一天和后一天、上一周和下一周、上个月和下个月、上一季度和下一季度、上一年和下一年，例如 `📅 day 2024-03-06 (后一天 - 星期三)` 或 `📅 day 2024-W09 (上一周 - 第 9 周)`。比当前笔记短的周期会被跳过，所以周笔记不会列出天。在列表页面中选择列出哪些项、按什么顺序，以及是否提供尚不存在的笔记。
- 出链：列出当前笔记链接到的笔记，包括属性中的链接。
- 入链：列出链接到当前笔记的笔记。
- 同一天：列出与当前笔记在同一天创建的笔记。对于日笔记，使用的是名称中的日期，而不是文件的创建时间。

其他列表不依赖当前笔记：

- 筛选：列出满足一组条件的笔记，例如 `status 等于 active`、带有 `#project` 标签的笔记，或 `work` 中最近一周修改过的笔记。条件可以分组，详见“列表页面”。
- 链接到笔记：列出在正文或属性中链接到指定笔记的笔记。
- 在文件夹中：列出某个文件夹及其子文件夹中的笔记。
- 今天修改：列出自午夜以来修改过的笔记。
- 当前日期笔记：列出今天、本周、本月、本季度和今年的日期笔记，只包括你开启的那些。它们按列表页面中设置的顺序排列（默认从今天到今年），而不按名称排序，每一行都会注明对应的周期，例如 `本周 - 第 10 周`。除非关闭“显示尚不存在的笔记”，尚不存在的笔记显示为 `创建本周`，选择它会按照你的日期笔记插件的方式创建并打开它，并使用相同的模板：Periodic Notes，或者对日笔记使用核心插件“日记”。来自自定义格式的周期会创建为空笔记。在链接属性中使用此来源时，只会提供已存在的笔记。

一篇笔记会出现在所有包含它的列表下，按列表的顺序排列，当前笔记本身不会出现。在同一个列表内，笔记按名称排序。如果所有列表都没有笔记，命令会提示“没有可跳转的笔记。”，而不是打开一个空的选择器。

每一行都以所属列表的前缀开头，前缀显示为一个小标签，与名称区分开。同一选择器中的所有标签宽度相同，以最宽的那个为准（最多约十二个字符），这样名称就能对齐；设置了前缀颜色的列表会为其标签着色。日期笔记会在名称后附上周期：日笔记显示星期几，周笔记显示 `第 N 周`，月笔记显示月份名称（如 `三月`），年笔记显示 `年度`。

如果想在不打开笔记的情况下编辑它的属性，可以在该行上按 ⌥↵（Alt+Enter），或点按行尾的滑块图标。桌面端只在高亮行上显示该图标，手机上则每一行都显示。两种方式都会为那篇笔记（而不是当前笔记）打开“设置属性”。会创建缺失日期笔记的行没有这个图标。在这个“设置属性”中按 Esc、选择 `🛑 取消` 或 `🏁 保存并返回列表`，都会带着你之前输入的内容回到跳转列表，方便连续编辑多篇笔记。

输入文字会按顺序匹配来筛选各行：只要你输入的字符按相同顺序出现在某一行中（不区分大小写，中间可以夹杂其他字符），这一行就会保留。前缀也是行的一部分，所以输入前缀的一部分就能把选择器缩小到那个列表。

### 日期笔记

如果一篇笔记直接位于为其周期设定的文件夹中，并且名称与该周期的格式完全匹配，它就是日期笔记。共有五个周期：日、周、月、季度和年，每个周期都有自己的文件夹、格式和开关。

设置主页面上的“日期笔记来源”设置决定这些格式从哪里来。“自动”在启用了 Periodic Notes 插件时使用它，否则使用核心插件“日记”，再否则使用本插件自己的自定义格式。“日记”只涵盖日，所以其他周期来自“自定义”。只要有周期来自“自定义”，“日期笔记来源”旁边就会出现一个铅笔图标，用来打开这些格式，你可以在其中为每个周期设置文件夹，并以 Moment 格式设置其格式：

https://momentjs.com/docs/#/displaying/format/

默认情况下，所有周期都位于 `on/`，格式分别为 `2024-03-05`、`2024-W10`、`2024-03` 和 `2024`；季度（如 `2024-Q1`）默认关闭。

## 设置属性

“设置属性”在一个选择器中编辑当前 Markdown 笔记的属性。只有当焦点在 Markdown 笔记上时，它才会出现在命令面板中。

在选择器中操作时不会写入任何内容。最前面两行始终是 `🏁 保存并关闭`（只写入你更改过的属性）和 `🛑 取消`（放弃所有更改）。按 Esc 与“取消”效果相同。在任何地方（包括某个属性自己的选择器中）按 ⌘↵，或在 Windows 和 Linux 上按 Ctrl+Enter，都会保存目前的内容并关闭选择器。

接下来是笔记保存时将带有的值，每个都标有 `✓`：每篇链接的笔记占一行，每个复选框、文本、数字或日期也各占一行，并在旁边显示其值。本次会话中更改过的值还会标有 `•`。选择一个已设置的链接会将其移除，于是多链接属性就少了这一篇笔记。选择一个已设置的文本、数字或日期会打开它自己的选择器；选择一个已设置的复选框，则按“复选框行为”设置执行。

在已设置的值下方，每个启用的属性会按设置中的顺序提供可以添加的内容：

- 链接或多链接属性会列出其来源中尚未设置的笔记，最近修改的排在前面。选择一篇会把它添加到多链接属性中，或替换链接属性中的那篇笔记。链接保存为列表，例如 `["[[Alice]]", "[[Bob]]"]`；属性中已有但其来源不提供的链接会被保留。
- 尚未设置的文本、数字、日期或日期 & 时间属性会显示一行属性名，选择后打开它自己的选择器。仓库中已有的值在那里提供，而不是在这里。
- 文本或数字属性还会在这里列出开启了主菜单开关的预设值，选一次即可设置。
- 当你输入的内容不是这些预设值之一时，文本属性还会提供 `✏️ <属性>：使用“<输入的内容>”`。
- 尚未设置的复选框会显示一行属性名。默认情况下它会打开自己的选择器。如果选择了“在 true 和未设置之间切换”，选择它会设为 `true`，在它为 `true` 时再次选择则会清除。如果选择了“依次切换 true、false 和未设置”，每次选择都会前进一步：从未设置到 `true`，再到 `false`，然后回到未设置。

没有输入任何内容时，每个属性最多显示五个值，后面跟着 `… 还有 N 项，输入以筛选`，选择它会替你输入该属性的前缀。一旦开始输入，所有匹配的行都会显示。选择一个值后，选择器会重新打开并清空筛选，于是 `🏁 保存并关闭` 又回到顶部，你刚选的值作为已设置的值显示在它下方。

![输入“joan”后的“设置属性”：Joan Puig 已被设置并标记为已更改，status 属性提供将“joan”用作新值](docs/images/set-properties-search.png)

“多个属性”模式的行一次选择就能设置多个属性，例如 `status: done`、`archived: true` 并移除 `active`。它的值在其属性页面中固定，因此选择器从不询问。该行在选择器中是一个选项，显示为它的“名称”；名称为空时显示其值的摘要，例如 `status done, archived ✓, active 已清除`，其中属性用正常颜色，值显示为灰色。只要笔记还没有全部这些值，该行就出现在可添加的内容中，选择它会一次应用所有值，并重新打开选择器、清空筛选。笔记具备全部值后，该行出现在已设置的值中并标有 `✓`；如果打开选择器时尚未具备，还会标有 `•`。此时选择它不会更改任何内容。多链接值会添加其笔记并保留其他链接，链接值会替换笔记，已清除的值会移除该属性。今天和现在在打开选择器时确定。该行要么全部成立，要么不成立：只有所有值都成立时才算已设置，并且在保存之前不会写入任何内容。

属性自己的选择器会用 `✓` 标记当前值，并以 `🗑️ 清除` 结尾，它会移除该属性；如果关闭了“为空时移除”，则只将其清空。按 Esc 会回到主选择器而不更改该属性，你在主选择器中已经做的更改会保留。

- 复选框提供 `true` 和 `false`。
- 文本提供用于新值的 `✏️ 使用“<输入的内容>”`，然后是它的预设值，再然后是该属性在仓库中已有的其他值，最常用的排在前面，并显示每个值的使用次数。
- 数字提供用于数字的 `✏️ 使用“<输入的内容>”`，然后是它的预设值，再然后是该属性在仓库中已有的其他数字，最常用的排在前面。
- 日期为以 `YYYYMMDD` 或 `YYYY-MM-DD` 输入的日期提供“使用”，然后是“今天”“明天”“下周一”和“一周后”，并保存为 `YYYY-MM-DD`。
- 日期 & 时间为 `YYYYMMDDHHmm`、`YYYYMMDD HHmm`、`YYYY-MM-DD HH:mm` 或 `YYYY-MM-DDTHH:mm` 提供“使用”，然后是“现在”，并保存为 `YYYY-MM-DDTHH:mm`。

![日期属性的值选择器，其中有“今天”“明天”“下周一”“一周后”和“清除”](docs/images/set-properties-date.png)

链接属性从不提供当前笔记和属性排除文件夹中的笔记。要隐藏已归档等笔记，请使用筛选来源，在“不满足以下任何条件”分组中加入 `archived 为 true`。选择器只能链接已存在的笔记，所以要链接一篇新笔记，请先用表单创建它。

## 表单

表单通过几个问题创建一篇新笔记，例如询问书名和作者的阅读记录，或询问主题和参与者的会议笔记。表单在 设置 → Note Compass → 表单 中定义。“填写表单”会列出你启用的表单，并运行你选择的那个；每个启用的表单本身也是一个以表单名称命名的命令，因此可以为它设置快捷键。与其他命令一样，无论是否有当前笔记都可以使用。没有表单时，“填写表单”会提示“还没有表单。请在 设置 → Note Compass → 表单 中添加。”

表单为每个询问字段提出一个问题，顺序与其“字段”列表一致。按 Esc 回到上一个问题，在第一个问题上按 Esc 会关闭表单，不创建笔记。返回时，你已经给出的答案会保留，并带有勾号。

最后一个问题之后会打开一个摘要。第一行是 `✅ 创建“<名称>”`，其中是根据你的答案得出的笔记名称；接着每个字段一行，显示它将得到的值或 `已跳过`；最后是 `🛑 取消`。选择一个询问字段会重新打开它的问题，回答后回到摘要；在摘要上按 Esc 会回到最后一个问题，如果表单没有问题，则关闭表单。所有必答问题都有答案后，在任何问题上按 ⌘↵，或在 Windows 和 Linux 上按 Ctrl+Enter，都会创建笔记。

笔记存放在表单的“文件夹”中；留空时，存放在 Obsidian 放置新笔记的位置。如果那里已有同名笔记（不区分大小写），新笔记会加上编号，例如 `Dune 2`。先写入笔记正文，再按字段顺序写入属性。然后 Note Compass 会提示笔记的位置，例如 `已在 reading 中创建“Dune”。`，并打开它，除非关闭了“创建后打开笔记”。

### 表单页面

表单的页面包含：

- “启用”：在“填写表单”中提供该表单，并作为命令提供。
- “名称”：显示在“填写表单”中，并作为命令名称。
- “笔记名称”：新笔记名称的模式，例如 `{{date:YYMMDDHHmm}} {{book}}`。空占位符造成的重复空格会被合并；如果名称最终为空，或包含 Obsidian 无法用于文件名的字符，则会被拒绝并显示提示，你会停留在摘要中。
- “笔记内容”：新笔记的正文，可使用相同的占位符。
- “文件夹”：新笔记的存放位置。
- “创建后打开笔记”：默认开启。
- “字段”：表单填入或询问的值。它们的顺序就是问题的顺序。

字段列表的用法与设置中的其他列表相同：拖动把手调整顺序，用复制图标在正下方复制一个字段，用叉号删除字段，用标题中的 `+` 添加字段。`+` 会打开一个菜单：“空白字段”添加一个空的询问文本字段，而“日期”“时间”“时间戳”和“ISO 时间戳”添加一个在创建时取值的固定字段，键为 `date`、`time`、`timestamp` 或 `iso-timestamp`，格式为 `YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm` 或 ISO 8601。每一项都会显示它此刻会写入的内容，已被使用的键会加上编号，例如 `timestamp-2`。“确认条目日期”和“确认条目时间”添加询问变量 `entry-date` 和 `entry-time`，两者可同时使用。

日期输入 `YYYYMMDD`，时间输入 `HHmm`，均为文本。下方选项预览完整的 `YYYY-MM-DD HH:mm`，按 Enter 保留显示值。更改日期保留时间，更改时间保留日期，在最终检查中重新编辑也一样。合并的日期时间用于 `{{date}}`、`{{time}}`、笔记名称及“创建时”的固定字段。现有配置继续保留，日期时间类型仍更改完整时间戳。只有多个字段更改同一部分时才会警告。每一行显示字段的键，后面跟着表示保存位置、模式和类型的小徽章，例如 `book` `变量` `询问` `文本`。属性徽章为蓝色，变量徽章为紫色。点击该行或其箭头可在其正下方编辑字段，再次点击则收起。一次只展开一个字段，新字段会直接展开。

名称、内容、固定的文本值和列表项支持以下占位符：

- `{{date}}` 和 `{{time}}` 是表单开始的时间，格式取自核心插件“模板”的设置。`{{date:FORMAT}}` 和 `{{time:FORMAT}}` 使用给定的格式。
- `{{key}}` 是名为 `key` 的字段的值。列表以逗号连接，跳过的字段为空。
- `{{key:FORMAT}}` 用给定的格式显示日期或时间字段，例如 `{{started:dddd}}`。
- `{{title}}` 仅用于内容，表示新笔记的名称。
- `{{today}}`、`{{tomorrow}}` 和 `{{yesterday}}` 是条目日期、次日和前一日，采用 Date notes 来源的日记格式，没有格式时为 `YYYY-MM-DD`。`{{today:FORMAT}}` 使用给定的格式；名为 `today` 的字段优先于占位符。
- 放在链接里的占位符，如 `[[{{today}}]]`，会链接到它所指的笔记，变成 `[[2026-10-31]]`。

其他占位符保持原样。

在这些输入框中，于开头或空格、`[`、`(` 之后输入 `@` 会打开表单已知占位符的菜单，并按 `@` 后输入的内容过滤：带有当前日期预览的 `today`、`tomorrow` 和 `yesterday`，表单的每个键（包括条件块中的字段），`date`、`time`，以及内容中的 `title`。每一项有两种形式：原样的 `today` 和链接形式的 `[[today]]`。选中一项后，`@` 和已输入的内容会被替换为一个胶囊。胶囊是一个整体，光标会跳过它，Backspace 或 Delete 会整个删除。Escape 关闭菜单并保留已输入的文本。手动输入或粘贴的占位符（如 `{{book}}`）同样显示为胶囊，`[[{{book}}]]` 显示为一个链接胶囊；表单中没有的键以虚线边框显示并保持原样。设置中保存的是带 `{{…}}` 的纯文本，胶囊只是输入框的显示方式。

### 字段

每个字段都有“键”、“存储为”、“填写方”，询问字段还有“问题”，然后是“字段类型”。“键”是属性名或变量名，两种情况下都用作 `{{key}}`。“存储为”可以是“属性”（默认），把值以其键写入新笔记的属性；也可以是“变量”，其值只用于填充名称和内容中的占位符，从不写入。“填写方”为“固定值”或“提问”。

固定字段可以是文本、数字、复选框、列表、日期、时间或日期 & 时间。数字只保留数字，复选框是一个开关。列表有一个输入框，其中每一项显示为一个标签：输入一项并按 Enter 添加，用它的 × 移除。项目可以是链接，因此 `[[Books]]` 和 `[[Reading]]` 会写入 `categories: ["[[Books]]", "[[Reading]]"]`，表单就是这样把它的笔记链接到其他笔记的。在固定的文本值或列表的输入框中输入 `[[` 会提示仓库中的笔记，选中一篇即写入它的链接，例如 `[[Books]]`，只有两篇笔记同名时才会带上文件夹。在列表的输入框中，选中的链接会立即变成一个标签。固定的文本值和列表的每一项也可以用与笔记名称相同的占位符，由表单的其他字段和日期组合而成，字段顺序无关：项目为 `[[today]]` 的 `dates` 列表写入 `dates: ["[[2026-10-31]]"]`，把新笔记链接到今天的日记；内容为 `{{book}} rated {{rating}}` 的 `summary` 文本写入 `Dune rated 4`。因所用字段被跳过而变为空或 `[[]]` 的项目会被丢弃，变为空的文本不会写入，条件块的条件按组合后的值比较。

询问字段可以是文本、数字、复选框、单选、多选、日期、时间或日期 & 时间。“问题”是提示语，留空时使用字段的键。“可选”会在问题的最前面放上 `⏭️ 跳过`；跳过的属性完全不会写入，跳过的变量为空。文本或数字问题接受你输入的任何内容，文本或数字属性还会提供该属性在仓库中已有的值。

单选和多选有“选项”，每个选项有一个值和一个可选的标签。“选项”标题中的 `+` 添加选项，叉号移除选项，拖动选项的把手可调整顺序。问题中显示标签，没有标签时显示值，笔记得到的是值。多选问题可以选择多个选项（带勾号），并以 `🏁 完成` 结束。“选项值类型”把值写为文本或数字，因此值为 `4`、标签为 `4 · 很棒` 的选项可以写入数字 4。

日期、时间和日期 & 时间字段有“格式”：`YYYY-MM-DD`、`HH:mm`、`YYYY-MM-DDTHH:mm`、ISO 8601，或自定义的 Moment.js 格式。固定字段的“值”取自“创建时”，即表单开始的时间；取自“指定日期”，即你在下方输入的日期；或取自“来自字段 …”，即表单中另一个日期或时间字段的值。指定日期用数字输入，日期为 `YYYYMMDD`，时间为 `HHmm`，日期 & 时间为 `YYYYMMDDHHmm`，也可以带短横线和冒号，下方的一行会显示读取的结果，例如 `✓ Mon 30 Oct 2028, 09:00`。这样，一个询问的时间就可以填入多个属性，例如格式为 `YYYY-MM-DD` 的 `day` 和格式为 ISO 8601 的 `timestamp`。如果来源字段被跳过，它也会被跳过。询问字段提供“现在”，日期还提供“今天”、“明天”、“下周一”和“一周后”。你也可以输入 `20240311`、`2024-03-11`、`0930`、`09:30`、`202403110930` 或 `20240311 0930`，与“设置属性”中的日期选择器相同。时间指的是今天的那个时间。

区块把只在前面的回答匹配时才使用的字段归在一起，例如只在笔记是关于一本书时才询问页数。“字段”标题的 `+` 菜单中的“条件区块”会在列表末尾添加一个空区块，区块底部的 `+` 会在其中添加字段。把字段拖到区块标题和底部行之间即可放入区块，拖出去则回到列表。拖动区块标题会移动整个区块，区块不能放进另一个区块。删除区块时，其中的字段会保留在列表中。点击标题可编辑条件：每个条件选择区块上方的一个字段、按字段类型提供的检查（如“等于”“含有项”“=”“早于”“已设置”），大多数情况下还要选一个值；单选字段会把选项作为值提供，日期和时间按 `YYYYMMDD`、`HHmm` 或 `YYYYMMDDHHmm` 输入。只有所有条件都成立时才使用该区块。未使用的区块不会提问，其字段不出现在摘要中、不会写入，占位符为空。多个字段可以使用同一个键（例如两个区块中各有一个 `categories`）：有值的最后一个字段生效，跳过的字段不会清除前面字段的值。

没有键的字段、没有选项的单选，或取自非日期字段的日期，都会在字段所在行和表单上显示警告。没有条件或字段的区块、缺少字段或值的条件、针对不在区块上方的字段的条件，或不适用于该字段类型的条件，会在区块所在行和表单上显示警告。此版本的 Note Compass 无法读取的表单会以关闭状态留在列表中，显示警告且没有铅笔图标，就像无法读取的列表一样，其保存的配置会一直保留，直到你删除它。

## 任务命令

用自己定义的命令面板命令处理当前 Markdown 笔记中的任务。

### 快速上手

在设置 → Note Compass → 任务中用 `+` 添加命令并命名。打开 Markdown 笔记，从命令面板运行该名称，也可以分配快捷键。只有启用且至少有一个操作的命令才会提供。没有匹配任务时会显示通知，而不是打开空选择器。

![日记上的任务选择器，最前面是 ⚡ 应用到全部 5 个任务，下面是未完成的任务，接着是带更改数量的 🏁 结束处理，最后是 🛑 取消](docs/images/task-picker.png)

### 命令页面

| 设置 | 作用 |
| --- | --- |
| 启用 | 将此任务命令作为独立命令提供。 |
| 名称 | 在命令面板中显示为命令名称。 |
| 列出的任务 | 留空则列出所有任务。 |
| 要跳过的任务 | 即使在列出范围内也会排除。留空则不跳过任何任务。 |
| 全选 | 添加一个首行，将操作应用到所有列出的任务。 |
| 批量模式 | 暂存操作，直到结束处理或没有剩余任务时才保存。取消或按 Esc 会放弃所有暂存的更改。 |
| 按键 | 把回车、Cmd+回车（Windows 和 Linux 上为 Ctrl+回车）、Alt+回车或 Shift+回车绑定到一个操作、“显示操作菜单”，或在批量模式下绑定到 `🏁 结束处理`。用 `+` 添加，用 × 移除。每个按键只能出现一次；没有条目的按键会打开操作菜单，所以列表为空时任何按键都会打开菜单。删除操作时会一并移除它的按键。 |

“添加状态”提供 未完成 `[ ]`, 已完成 `[x]`, 已取消 `[-]`, 已迁移 `[>]`, 已安排 `[<]`, 进行中 `[/]` 和“自定义…”。自定义状态需输入一个字符并按回车添加，用标签的 × 移除。状态区分大小写，跳过条件优先。

表单和任务的行只显示名称；第二行仅在有警告时显示，不再显示配置摘要。
无法读取的命令会保持关闭并显示警告，直到将其删除。

### 操作

每个操作有“标签”、一种“操作”和一个字符的“状态”。用 `+` 添加、拖动排序、复制图标复制、× 删除；点击行可在下方编辑。

#### 更改状态

更改原任务行的复选框字符。“完成日期”可以添加后缀。

| 完成日期 | 添加的文本 |
| --- | --- |
| 关闭 | 无。 |
| 日期 | ` ✅ 2028-10-30` |
| 日期链接 | ` ✅ [[2028-10-30]]` |
| 时间戳 | ` ✅ 2028-10-30 09:00` |

示例日期使用“日期笔记”的日记格式，日期是今天，而不是原笔记的日期。时间戳添加核心模板插件的时间格式。日期链接不会创建笔记。

#### 复制到笔记

将未完成的任务 `[ ]` 追加到另一篇笔记末尾，并设置原任务的“状态”。只复制任务这一行，不复制子任务、续行、缩进或引用前缀。

- “目标”打开独立页面：用 `+` 添加、拖动排序、× 删除，返回箭头回到命令。
- 复制任务的前缀和后缀仅原样添加到副本正文，位于块 ID 和来源链接之前。请自行包含空格；默认留空，即时和批量处理均适用。
- “链接目标笔记”在原任务添加 ` → [[目标]]`；“链接来源笔记”在副本添加 ` ← [[来源]]`。
- 周期相对于今天，而不是原笔记日期，使用“日期笔记”中启用的周期、文件夹和格式。一个可用目标直接执行；多个目标按配置顺序打开“复制到哪个笔记？”。不提供原笔记和重复目标。
- 不存在的指定笔记会被跳过并显示通知。若没有剩余目标，不会更改任何内容。
- 缺失的周期笔记在保存时创建。如果“日期笔记”使用 Periodic Notes，会先请求该插件使用模板创建笔记。若 API 不可用、失败或未创建预期路径，则创建空笔记。其他来源，包括核心日记和自定义，都会先创建空笔记再追加任务。

![“迁移”的“复制到哪个笔记？”，提供明天、本周、标为新笔记的下周以及本月，每一项都带有其笔记的名称](docs/images/task-destinations.png)

### 选择器和批量模式

![操作菜单“应用哪个操作？”，其中有 ✅ 完成、🚫 取消、➡️ 迁移和 📅 安排](docs/images/task-actions.png)

- 输入文字按字符顺序、不区分大小写地筛选任务文本。“按键”中的按键执行绑定的操作；其他按键或 ⚙ 打开所有操作。
- “全选”在搜索匹配多个任务时添加 `⚡ 应用到全部 N 个任务`。只处理匹配搜索的任务，而不是整篇笔记。
- 启用“批量模式”时，每次选择都会暂存，然后重新打开选择器，显示剩余任务并清空搜索。`🏁 结束处理` · N 项更改 保存全部更改。任务选择器中的 `🛑 取消` 或 Escape 放弃所有暂存更改。在操作或目标选择器中按 Escape 只会返回，保留之前暂存的更改。
- 处理最后一个任务会自动保存并结束。选择 `⚡ 应用到全部 N 个任务` 也会立即保存并结束，即使搜索隐藏了其他任务。
- 关闭“批量模式”时，一次选择立即写入并关闭选择器；Escape 无法撤销。两种模式都会跳过选择器打开后被修改的原任务行，并显示通知。

### 新命令的默认值

新命令采用 Bullet Journal 配置，名称为“处理未完成的任务”：启用，只列出未完成 `[ ]`，不跳过任何状态，“全选”关闭，“批量模式”开启。“按键”把回车绑定到“✅ 完成”，因此 Alt+回车、Cmd+回车和 Shift+回车会打开操作菜单。

| 操作 | 原任务状态 | 其他设置 |
| --- | --- | --- |
| ✅ 完成 | `[x]` | 完成日期：关闭。 |
| 🚫 取消 | `[-]` | 完成日期：关闭。 |
| ➡️ 迁移 | `[>]` | 明天, 本周, 下周, 本月; 只链接目标。 |
| 📅 安排 | `[<]` | 下个月, 下季度, 明年; 链接目标和来源。 |

这些默认目标只适用于新命令，已保存的目标不变。

### 已知行为
- 跨多篇笔记的写入不是原子操作：失败时可能只有部分笔记更新。
- 复制保留行文本，包括现有后缀和块 ID；块 ID 会重复，而不是重新生成。

## 设置

设置页面适配窄窗口，在移动端的用法也相同。主页面开头是一段简短说明，介绍“导航”、“属性”、“表单”和“任务”这四个页面各自包含什么；接着是这四个页面、“集成”分组中的“日期笔记来源”，最后是“重置所有设置”。

![设置主页面，顶部是 Note Compass 的结构说明，接着是“导航”、“属性”、“表单”和“任务”页面，“集成”中的“日期笔记来源”，底部是“重置所有设置”](docs/images/settings.png)

点击四行中任意一行的任意位置即可打开它的页面，用顶部的返回箭头返回。某一行自己的页面在它所属的分区内打开，因此从某个列表的页面返回时会回到它所属导航选择器的页面，再返回一次则回到“导航”页面。该页面列出你的导航选择器，添加、排序、开关、编辑、复制和删除的操作与其他设置列表相同；每个选择器有“启用”“名称”“筛选”和它的列表。选择器的筛选在每个列表自身的来源和筛选之外应用于所有列表，只显示符合的笔记；为空时不隐藏任何笔记。新选择器不含列表、筛选为空，复制图标会连同筛选和所有列表一起复制。

![导航选择器的页面，每个列表显示为一行，带有前缀标签、开关、复制图标、铅笔图标和删除按钮](docs/images/settings-jump-to-note.png)

### 表单和任务

使用与其他列表相同的添加、排序、启用、编辑、复制和删除控件。命令页面包括命令、列出的任务、要跳过的任务、选项和操作。添加之前没有任务命令，新命令采用 Bullet Journal 操作。

表单和任务的行只显示名称；第二行仅在有警告时显示，不再显示配置摘要。

### 列表和属性

导航选择器的页面和“属性”页面都是由行组成的列表，它们的行用法相同。每一行显示其前缀标签，以及它列出或写入的内容，例如 `status 等于 active` 或 `people · 多链接`。

- 拖动左侧的把手来调整行的顺序。这个顺序就是选择器中的顺序。
- 用开关在选择器中显示或隐藏某一行，而不会丢失其配置。
- 用铅笔图标打开该行的页面，用叉号删除该行。
- 用复制图标复制一行。副本出现在该行正下方，设置相同，表单的副本名为 `<名称> 副本`。
- 用列表上方的 `+` 添加一行。它的页面会立即打开以便填写，新行默认处于开启状态。

此版本的 Note Compass 无法读取的行（例如由更新版本保存的行）会留在列表中并显示警告：“此版本的 Note Compass 无法读取该列表。请删除它并新建一个。”它的开关处于关闭且禁用状态，也没有铅笔图标，因此它不会向选择器添加任何笔记，但其保存的配置会原样保留，直到你删除它。

点击或轻触前缀标签，或让它获得焦点后按 Enter，即可打开它的菜单；在手机上，菜单会以底部面板的形式出现。菜单列出所有导航选择器和“属性”页面中正在使用的每个前缀，每个前缀显示为它的标签，后面跟着使用它的行数，例如 `📅 due` 标签后跟 `· 3 行`，使用最多的排在前面。该行自己的前缀带有勾选标记。选择一个前缀，会把它的文本和颜色赋给这一行，其他行都不变。“编辑前缀…”会打开该行的页面，并把光标放在“前缀”中；“无前缀”只在该行有前缀时出现，用于清除它的文本和颜色。空前缀显示为一个淡色的 `前缀` 标签，并且从不出现在菜单中。

两行的文本和颜色都相同时，才算共用同一个前缀，所以红色的 `👤 peop` 和没有颜色的 `👤 peop` 是两个前缀。

### 列表页面

列表页面中有“启用”和“前缀”，然后是“来源”，用来选择列表包含的内容：相邻日期、出链、入链、同一天、筛选、链接到某篇笔记的笔记、文件夹中的笔记、今天修改的笔记，或当前日期笔记。相邻日期和当前日期笔记会在来源下方增加两个设置。“显示尚不存在的笔记”关闭时只列出已存在的日期笔记；开启时也会列出缺少的笔记，例如 `创建下一周`，选择它即可创建。默认情况下，相邻日期为关闭，当前日期笔记为开启。“要列出的笔记”每项一行，默认全部开启：相邻日期为“前一天”“后一天”直到“上一年”“下一年”，当前日期笔记为“今天”到“今年”。拖动某行的手柄可以改变选择器中的显示顺序，关闭某行即可将其排除。缺少的相邻日期笔记在日期笔记来源为 Periodic Notes 时用其模板创建，其他情况下创建为空笔记。

![相邻日期列表的页面，“显示尚不存在的笔记”处于关闭状态，下方“要列出的笔记”列出前一天、后一天、上一周、下一周等周期，每行都有开关和拖动手柄](docs/images/list-adjacent-dates.png)

在列表或属性页面上，“前缀”显示设置按钮、标签的预览、它的文本和颜色。你输入的文本和选择的颜色会更改这一行，以及打开页面时与它共用该前缀的所有行，说明中会列出这些行，例如“另有 2 行使用：people · 多链接, 出链”。即使文本暂时为空，它们也会保持一致。环形箭头用于移除颜色。

设置按钮（“选择前缀”）会打开前缀菜单。选择一个前缀会把它的文本和颜色赋给这一行，其他行不变。“新建前缀…”在该行有前缀时显示，会清空它，因此你接下来输入和选择的内容只更改这一行。“无前缀”在该行有前缀时显示，会清除其文本和颜色。

筛选的用法和外观都与 Obsidian 数据库（Bases）中的筛选相同。它是一个以“满足以下所有条件”“满足以下任意条件”或“不满足以下任何条件”开头的组，因此当一篇笔记匹配组中所有筛选器、至少一个，或一个都不匹配时，它就会被列出。每个筛选器行都以它要检查的对象开头：输入属性名，或从建议中选择 `文件夹`、`标签`、`链接`、`创建时间` 或 `修改时间`。然后选择运算符和值，例如 `文件夹 位于 projects`、`标签 有标签 client` 或 `修改时间 晚于 7 天前`。“添加筛选器”向组中添加一行，“添加筛选器组”在其中添加一个带有自己选项的子组。组可以嵌套在组中，最多三层（筛选本身算一层）。行或内部组上的垃圾桶按钮可将其移除，移除内部组的最后一行时该组也会被移除。新建的筛选没有任何行，在你添加之前不会列出任何内容；筛选中的空组不参与匹配。

每个条件首先要选择它查看的对象：

- 属性：按其类型提供的条件检查某个属性，详见下文。
- 文件夹：用“位于”匹配某个文件夹及其子文件夹中的笔记，或用“不位于”匹配其他所有笔记。
- 标签：匹配在属性或正文中带有某个标签的笔记。标签也会匹配其子标签，所以 `project` 能匹配 `#project/website`，大小写和开头的 `#` 都无关紧要。“没有标签”匹配不带该标签的笔记。
- 链接到笔记：匹配在正文或属性中链接到指定笔记的笔记，“不包含”则匹配没有链接到它的笔记。
- 创建时间和修改时间：用“在”“不在”“早于”或“晚于”，将笔记的创建日或最后修改日与一个固定日期或相对于今天的日期进行比较。

列表的行会显示筛选中唯一的条件，例如 `status 等于 active` 或 `有标签 project`，或者显示条件数量，例如 `满足全部 3 个条件`。

早期版本保存为“带有某属性的笔记”的列表，会以只包含该属性条件的筛选打开，列出的笔记与之前相同。

属性条件会先要求选择属性（会建议仓库中的属性及其类型），然后选择该类型提供的条件：

- 复选框属性可以为 true、为 false、已设置或未设置。“为 false”需要显式的 `false`。
- 文本属性可以等于或不等于某个值、包含或不包含它、已设置或未设置。
- 列表、标签和别名属性可以含有或不含有等于该值的项、已设置或未设置。Wiki 链接按链接文本比较，所以 `[[Project]]` 能匹配值 `Project`。
- 数字属性可以等于、不等于、小于（`less than`）或大于（`greater than`）某个数字，已设置或未设置。
- 日期属性可以在、不在、早于或晚于一个固定日期、今天，或若干天前或若干天后，已设置或未设置。相对日期在每次打开选择器时重新计算。

“未设置”也会匹配留空的属性。否定条件（如“不等于”或“不包含”）会匹配所有不满足对应肯定条件的笔记，包括没有该属性的笔记。

### 属性页面

属性页面有“启用”和“标签”分组，“标签”中有与列表页面相同的“前缀”，在“多个属性”模式下还有该行的“名称”。接着是“模式”，可以是默认的“单个属性”或“多个属性”。在“单个属性”模式下，后面是“属性”和“类型”。“属性”会建议仓库中的属性及其类型，选择一个会把类型设为相应的值：复选框、数字、日期和日期 & 时间保持不变，列表和标签变为多链接，其他都变为文本。“类型”可以是复选框、文本、数字、日期、日期 & 时间、链接，单篇笔记，或多链接，多篇笔记；在选择属性之前它处于禁用状态。

![people 多链接属性的页面：它的前缀标签与另一行共用，people 属性的类型为多链接，提供的笔记来自链接到 Person 的笔记](docs/images/settings-property.png)

每个属性都有“为空时移除”，它默认开启，在你清除属性的值或移除其最后一个链接后，会把该属性从笔记中移除。关闭后，该属性会以空值留在笔记中。

文本或数字属性还有“预设值”，即它自己的选择器首先提供的一组值，例如为 `status` 属性设置 `todo`、`doing` 和 `done`。标题中的 `+` 会添加一行，其中有一个用于填写值的文本框和一个开关；各行可以拖动来调整选择器中的显示顺序，也可以逐行删除。数字属性只保留以数字形式填写的值。预设值是辅助而不是限制：在预设值之后，选择器仍会提供该属性在仓库中已有的其他值（最常用的排在前面）以及你输入的任何内容。预设值旁的开关还会让它出现在“设置属性”主菜单中，因此你可以保留很多预设值，只把最常用的几个放在一步可选的位置。所有预设值始终会出现在该属性自己的选择器中。

链接或多链接属性还有两个部分：

- “提供笔记来源”选择选择器提供哪些笔记，可用来源与跳转列表相同。
- “排除的文件夹”列出其中笔记永远不会被提供的文件夹。标题中的 `+` 添加一个文件夹，每一行都可以删除，空行不排除任何内容。

“多个属性”模式的行会用页面上固定的值一次写入多个属性，“设置属性”选择器把它作为一个选项提供。把模式切回“单个属性”会恢复单个属性的设置，固定的值会保存下来，供下次切换使用。“名称”是选择器为该行显示的内容；为空时显示其值的摘要，该摘要也用作字段的占位文本。“要设置的值”中每个属性一个区块：标题中的 `+` 添加一个，区块可以拖动、复制和删除。每个区块显示其属性和值，例如 `status done`、`archived ✓` 或 `active 已清除`，点击即可打开其编辑器。

- “属性”是要写入的属性。聚焦时会列出仓库中的属性，选择一个会把类型设为相应的值。也可以使用新名称。
- “类型”可以是复选框、文本、数字、日期、日期 & 时间、链接，单篇笔记，多链接，多篇笔记，或“清除（删除属性）”。
- “值”对复选框是一个开关，或是一段文本、一个数字、今天或固定日期、现在或固定日期和时间，链接和多链接则是一篇笔记。清除没有值。

链接值会替换属性中已有的笔记，多链接值会把其笔记添加到列表中。没有属性或没有值的区块会被跳过。

多行可以写入同一个属性，例如默认的几个来源不同的 `related` 行。它们共享同一个值，由第一个启用的“单个属性”模式的行决定其类型。当同一属性的两行类型不一致时，行上会显示警告。

### 复选框行为

“复选框行为”位于“属性”页面的列表下方，决定在“设置属性”主菜单中选择复选框属性时的操作，适用于所有复选框属性：打开包含 true、false 和“清除”的选择器（默认），在 true 和未设置之间切换，或依次切换 true、false 和未设置。在 0.6.1 或 0.6.2 中为单个属性选择的模式会转为这个设置。

### 重置所有设置

“重置所有设置”位于主页面底部，会把所有列表、属性、表单和选项恢复为默认值，默认值中没有表单。它会先进行确认，选择“取消”或按 Esc 则一切保持原样。重置无法撤销。

重置也会删除任务命令；默认值不包含任务命令。

## 语言

Note Compass 跟随你为 Obsidian 选择的语言。它提供英语、西班牙语、简体中文、繁体中文、日语和韩语版本，其他语言则显示英语。无论使用哪种语言，你的设置、属性名称以及写入笔记的值都会保持你输入时的样子。

翻译位于 `src/i18n/`，本手册也提供上述每种语言的版本，可通过顶部的链接访问。两者都由机器翻译起草，因此有些措辞可能读起来不太自然，以英文版手册为准。欢迎以 pull request 的形式提交修正。添加一种语言只需在该文件夹中新增一个文件，并在其注册表中添加一行；某种语言尚未翻译的文本会以英语显示。

## 技巧

- 为这些命令设置不用看键盘就能按的快捷键。本插件的核心用法就是打开选择器、输入几个字母、按 Enter。
- 前缀尽量简短，例如一个表情符号加三四个字母的标记，像 `👤 peop` 或 `📅 due`。所有标签宽度都以最宽的那个为准，所以一个长前缀会把所有名称都推向右边。
- 用颜色为相关的列表分组，例如所有人物和公司列表用一种颜色，项目列表用另一种颜色，这样一眼就能区分。
- 输入前缀标记可以把选择器缩小到某个列表，例如在“设置属性”中输入 `peop` 来查看人物行。
- 把“链接到笔记”来源当作轻量的标签来用。创建一篇名为 `Person` 之类的笔记，并让人物属性指向“链接到笔记：Person”。在用来创建人物笔记的表单的内容中加入 `[[Person]]`，这样每个新人物无需手动加标签就会出现在列表中。
- 在每个链接属性的“排除的文件夹”中加入你的模板文件夹，这样模板笔记永远不会作为值被提供。
- 在“设置属性”中，在值选择器里按 Esc 只会退回主选择器。你已经做的更改会一直保留，直到你选择“保存并关闭”或“取消”。
- 在任务命令中，把最常用的操作绑定到“按键”，并留一个按键不绑定：这个按键和 ⚙ 仍会打开所有操作。开启“批量模式”时，把 Cmd+回车绑定到 `🏁 结束处理`，无需滚动到最后一行即可保存。

## 已知行为

- 包含 `/` 的日格式（如 `YYYY/MM/DD`）永远不会匹配，因为比较笔记名称时不包括其所在的文件夹。
- 使用默认格式时，日期笔记文件夹中以年份命名的笔记（如 `on/2024`）会被视为年笔记。如果你在该文件夹中还有其他这样命名的笔记，请在自定义格式中关闭年周期。
- 如果属性的类型发生变化，针对它的筛选条件会保留原来的条件，在你选择新条件之前不会匹配任何笔记。该条件、其所在列表的行和列表页面都会提示该条件已不再适用。
- 跨多篇笔记的写入不是原子操作：失败时可能只有部分笔记更新。
- 复制保留行文本，包括现有后缀和块 ID；块 ID 会重复，而不是重新生成。

## 开发

```bash
npm ci
npm run dev
npm run build
npm test
npm run lint
```

`npm run dev` 会在每次更改时重新构建，`npm run build` 进行类型检查并输出生产包，`npm test` 运行单元测试，`npm run lint` 运行与社区审核相同的 Obsidian lint 规则。

要在测试仓库中试用本插件，请把代码仓库以符号链接的方式放入其插件文件夹，这样测试仓库总是加载 `npm run dev` 刚刚生成的构建：

```bash
ln -s "$PWD" "<vault>/.obsidian/plugins/note-compass"
```
